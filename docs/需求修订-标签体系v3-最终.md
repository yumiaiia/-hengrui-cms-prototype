## 3. 模块六替换稿（可直接粘贴）

#### 6.1 功能目标

维护平台的"维度—取值"标签字典与可配置派生规则：分类维度承载业务标签，枚举字段承载内容固定属性（用户可见范围、推广性质、内容渠道）；规则统一以"整份内容命中一组取值 → 产出一组取值"管理，支持试算与即时重算；提供全入口名称/别名查重、推荐治理与三表 Excel 交换，并保留创建新版本式的批量标签同步。

#### 6.2 适用场景

维护维度与取值、配置与试算派生规则、Excel 导入导出、审核推荐标签；以及更新字典或规则后，对存量正式内容批量同步并归档生成新版本。

#### 6.3 业务规则

##### （1）维度与取值

1. **两层结构**：维度（根）+ 取值（叶）。不提供第三级；一个取值只能属于一个维度，**不支持跨维度移动**（需要换维度时停用后新建）。
2. **两类维度**：
   - **分类维度**：值是业务标签，授权用户可增删改名（内容类型、内容主题、产品、疾病领域、药物分类、治疗方案）。
   - **枚举字段**：值是内容固定属性，可新增（当前预置用户可见范围、推广性质、内容渠道）；创建时选定类型，**创建后不可更改**；取值可维护，但被规则或内容引用时不提供删除，只能停用。
3. **维度属性**：`基数`（单值/多值）、`作用域`（材料级/页级/两者）、`AI 匹配`（闭集/开放/不参与）、`合并策略`（并集/优先级）、`兜底值`（仅字段）、`允许人工修改`（仅字段）。
4. **取值属性**：名称、别名、排序、启用、对外展示、仅规则产生。
5. **维度禁止停用**：维度恒定启用；需要整体下线时逐个停用其取值。所有写操作记审计。
6. **取值不可删除，只能停用**：停用后不再产生新绑定，已有绑定保留并标 `已停用`。

##### （2）派生规则

1. **结构**：`触发（维度 + 一组取值 + 任一/全部） → 结果（维度 + 一组取值）`，附优先级与启停。触发统一为**整份内容并集**，不分页。
2. **求值输入**：只读取 `AI` 与 `人工` 产生的取值，以及人工设置过的字段；**规则产物不参与任何规则触发**，不存在链式与循环。
3. **合并**：
   - 目标维度 `合并策略 = 并集`：所有命中规则的结果取并集；
   - `优先级`：取优先级数字最小的一条命中规则结果。
4. **优先级必填且唯一**：同一目标维度下不允许重复；保存与导入时校验，冲突即阻断。
5. **人工优先**：目标维度 `允许人工修改 = 是` 且人工设过值时，规则不覆盖，界面给"规则建议"提示，可"恢复按规则"。
6. **禁止自派生**：触发维度与目标维度相同不允许保存。
7. **落库校验**：结果取值必须启用且未被排除；停用取值不产出，规则标记"结果部分不可用"。
8. **兜底**：目标字段所有规则均不命中时落兜底值；人工清空字段（记人工）后不再兜底。
9. **生效方式**：保存、停用、删除或导入规则后，**立即重算正式内容当前版本**（幂等，只重写规则产物，人工值不动），并提示重算份数。
10. **单值维度冲突**：人工 > 规则 > AI；同来源按取值排序 `order` 升序，order 相同按名称。

##### （3）用户可见范围

1. 它是**枚举字段**（多值），取值是受众集合，当前预置 `未注册 / 已注册待认证 / 已认证`；取值可维护，新增或改名后所有读取点自动跟随。
2. 不存在"All三类用户"这个标签值：三项全选时展示 `All三类用户`；部分选择按名称顿号连接；空为 `未设置`。
3. **它只是展示值，不参与任何权限判定，也不参与发布准入**。
4. 人工调整后标记人工，规则不再覆盖；"恢复按规则"清除人工标记并重算。
5. 兜底值为 `已认证`（最保守档）；人工清空后不兜底。

##### （4）名称、别名与推荐

1. **归一化**：`NFKC` + 去首尾空格 + 转小写后比较（全半角、大小写视为同名）。
2. **同一维度内硬阻断**：取值重名；别名与同维度其他取值的名称或别名重复；别名与自身名称相同或别名内部重复。
3. **跨维度允许同名同别名**：命名空间按维度隔离。
4. **相似提醒**：编辑距离 ≥ 0.7 时列出最多 5 项候选，可返回修改或仍然保存。
5. **推荐标签**：AI 产出的未入库候选词按"内容 + 版本 + 位置"生成推荐，落到**该推荐记录的所属维度**；采纳时若同名取值已入库则绑定已有值，否则在该维度下新建。
6. **单值维度采纳冲突**：同位置已有值时替换原值并记排除（与人工打标一致）。
7. **排除记忆**：按取值 ID + 位置记录；改名不失效；未入库推荐词回退"名称 + 维度"；**字段人工改动不使用排除记忆**，统一由"人工标记"表达。

##### （5）Excel 三表交换

1. 工作表固定 `维度` / `取值` / `规则`，表头固定，禁公式，布尔列填 `是/否`。
2. `维度`：ID、维度名称、类型、基数、作用域、AI 匹配、合并策略、兜底值、允许人工修改。
3. `取值`：ID、维度ID、维度名称、取值、别名、排序、仅规则产生、启用、对外展示。
4. `规则`：ID、规则名称、触发维度、触发取值、匹配方式、目标维度、结果取值、优先级、启用。
5. **校验**：规则按名称引用维度与取值，必须存在（同批新建可用）；**维度类型与库内不一致报错**；**同一目标维度优先级重复报错**；兜底值可写在后续取值表中。
6. 导入只做新增与更新，不删除；有错误整批不入库；相似项逐行处理；导入后立即重算。
7. 旧的双表模板不再接受，提示使用新模板。

##### （6）同步最新标签到文件

1. 字典口径：`AI 匹配 ≠ 不参与` 且非"仅规则产生"的全部启用取值。
2. **批次启动时冻结规则快照**，整批使用同一份规则；批次进行中修改规则不影响本批，仅新批次生效。
3. 100% 保留原有 `AI` / `人工` 绑定，只在未绑定且无排除记录的位置补充 `AI`，并按批次快照重算字段值与规则产物。
4. 归档与新建版本规则不变（生成 `V{N+1}.0`）。

| 合并策略 | 多规则结果如何合并 | 必填 | 并集/优先级 | 并集 | 选择 | 并集取全部；优先级取最小优先一条 | 无 |
| 兜底值 | 规则都不命中时的值 | 选填 | 该维度下已启用取值 | 空 | 选择 | 仅字段；人工清空后不兜底 | "兜底值不存在：{名称}" |
| 规则优先级 | 同字段多规则的先后 | 必填 | 整数，同目标维度唯一 | 50 | 输入/导入 | 仅"优先级"合并的维度生效 | "同一目标维度优先级不能重复" |
| 同步范围 | 批量同步选文件模式 | 必填 | 选择部分文件/全部（M） | 选择部分文件 | 单选 | 标题搜索 | "请至少选择一份正式内容" |

##### （8）关键状态

- **维度**：恒为 `启用`（不提供停用）。
- **取值**：`启用` / `已停用` / `仅规则产生`（可叠加）。
- **规则**：`启用` / `已停用`。
- **字段值**：`规则推导` / `人工设置` / `未设置`。
- **规则产物**：存在 / 已撤销（重算后）/ 已排除（人工移除后）。

##### （9）结果反馈与审计

- 保存维度/取值/规则、导入、采纳推荐、发起同步、重算：即时 Toast。
- 审计动作见模块十；导入记录三维度计数；重算记录份数。
- 列表只展示"触发→结果、优先级、状态、操作"，不展示来源、单条影响数或"待重算"状态。

#### 6.4 整体流程

1. 在`维度与值`维护维度与取值（字段取值同样可维护、字段可新增），在`派生规则`配置触发与结果，用"试算"选择一份内容验证结果。
2. `Excel` 三表整包导入导出；导入先预览，逐行处理相似与错误，确认后立即重算。
3. 规则或字典变更即时生效于正式内容当前版本；待归档批次按启动时冻结的规则快照计算。
4. 需要批量给存量内容补值时，发起"同步最新标签到文件"→ 模块四确认 → 归档生成新版本。

#### 6.5 关键状态

同 6.3(8)。

#### 6.6 结果反馈

同 6.3(9)；已有未结束标签更新批次时引导进入原批次。

## 5. 边界场景（建议新增为 6.3(10)， 可直接作验收用例）

### 5.1 命名与别名

| 场景 | 行为 |
| --- | --- |
| 同维度新增与已有名称仅全半角/大小写不同 | 归一化后视为同名，阻断 |
| 两个取值的别名相同 | 阻断，提示冲突取值名 |
| 别名与自身名称相同 / 别名内部重复 | 阻断 |
| 别名与另一取值名称相同 | 阻断（共用名称空间） |
| 两个维度下有同名取值（如"治疗"） | 允许，按维度隔离 |
| 改名后绑定与排除记忆 | 绑定按 ID 保留并即时更新展示；排除记忆按 ID 不受影响 |
| 导入同文件内重名/重别名 | 该行报错，整批不入库 |
| 别名为空或只有分隔符 | 视为未填，不报错 |

### 5.2 规则冲突

| 场景 | 行为 |
| --- | --- |
| 同字段多条规则命中，字段为并集 | 结果取并集 |
| 同字段多条规则命中，字段为优先级 | 取优先级最小的一条 |
| 两条规则同目标维度同优先级 | 保存/导入阻断，提示冲突规则名 |
| 不同目标维度同优先级 | 允许 |
| 规则与人工冲突 | 人工优先，给"规则建议"，可恢复按规则 |
| 规则与 AI 冲突（单值维度） | 人工 > 规则 > AI；同来源按 order |
| 触发维度 = 目标维度 | 阻断保存 |
| 规则 A 的产物作为规则 B 触发 | 不会发生（规则只读 AI/人工） |
| 结果取值被停用 | 该值不产出，规则标"结果部分不可用" |
| 触发取值被停用但内容仍绑定 | 仍视为命中（历史一致） |
| 停用/删除规则 | 立即重算，产物撤销；人工值保留 |

### 5.3 启停与下线

| 场景 | 行为 |
| --- | --- |
| 停用维度 | **不支持** |
| 停用取值（作触发） | 仍命中 |
| 停用取值（作结果） | 不产出 |
| 维度想整体下线 | 逐个停用取值 |
| 停用后恢复取值 | 可重新绑定；规则产物需重算补回 |

### 5.4 人工、兜底与排除

| 场景 | 行为 |
| --- | --- |
| 人工移除规则产物 | 按取值 ID + 位置记排除，重算不补回；人工重新添加解除 |
| 人工清空字段 | 标记人工，规则与兜底都不生效 |
| 人工只改部分受众 | 整个字段标记人工，其余项保持当前值 |
| 恢复按规则 | 清人工标记 → 重算；都不命中则落兜底 |
| 规则建议与人工一致 | 不显示冲突提示，仅标人工 |
| 字段人工改动 | 不使用排除记忆 |

### 5.5 导入导出与并发

| 场景 | 行为 |
| --- | --- |
| 规则引用被跳过的取值行 | 规则行报错，整批阻断 |
| 导入改维度类型 | 报错 |
| 同一目标维度优先级重复 | 报错 |
| 兜底值写在后面的取值表 | 整轮结束后解析，可识别 |
| 旧双表模板 | 拒绝并提示使用新模板 |
| 批次进行中改规则 | 不影响本批（冻结快照） |
| 规则变更 | 立即重算当前版本（含导入） |
| 影响面口径 | 仅当前版本；不含历史版本与批次暂存 |
| 历史版本 | 只读，不重算；字段值随版本快照展示 |
