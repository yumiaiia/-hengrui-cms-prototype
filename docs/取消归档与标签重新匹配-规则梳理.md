# 恒瑞 CMS：取消归档与标签重新匹配规则

> 日期：2026-11-24\
> 状态：规则已确认，已并入现有主设计并落实为原型交互。

完整设计以[本轮改版-产品设计建议](./本轮改版-产品设计建议.md)为准：取消归档见 4.6，推荐取消见 5.4，批量匹配的定义、范围、九类场景、交互和异常见 5.5—5.8。

## 已确认结论

维护完一批标签后，用户从“同步最新标签到文件”手动发起一次批量匹配。单个标签保存不自动触发，任务使用启动时的已启用标签库及已有解析结果，仅处理正式内容的正常、解析完成的当前版本；默认列表勾选部分文件，支持搜索、格式 / 来源筛选、跨页选择，也可显式切换全部文件。自动匹配仅补充尚未绑定位置的新命中，全部已有绑定保留，不自动解绑。

| 场景 | 完整结果中的变化 |
| --- | --- |
| 新增已启用标签 | 命中则加入对应文件或页面 |
| 新增停用标签 | 不参与匹配，不新增绑定 |
| 原有标签被停用 | 保留已有绑定，标记停用 |
| 一级分类被停用 | 分类下标签不参与识别，已有绑定保留 |
| 文件已有标签 | 自动与人工绑定全部保留，不重算、不重复添加；材料和各页独立判断已有绑定 |
| 标签重新启用 | 所属分类启用时，在下次主动批量匹配中补充未绑定位置；已有绑定及人工取消记录保留 |
| 标签名称修改 | 已有绑定按标签 ID 保留并显示新名称；未绑定位置按新名称匹配，不校验含义变化 |
| 标签所属分类修改 | 已有绑定保留并按新分类展示；新分类启用时，未绑定位置继续匹配 |
| 原有自动标签本次未命中 | 仍保留已有绑定，不自动移除；由用户手动维护 |
| 仅修改对外展示开关 | 绑定不变，展示设置生效，无需专门重跑 |

匹配结果生成“标签更新”批次，放在内容库待归档区域；复用文件队列、预览、素材查看及标签编辑。直接显示完整材料和页级标签，不展示增删建议及分类统计。用户可调整结果，逐份确认后点击“更新已确认的 N 份”。

正式内容在确认更新前使用原标签；更新后保持已归档，不生成文件新版本，不修改源文件、审批、展示素材和已提交发布快照，不自动重新发布。

取消归档和取消标签更新均只结束尚未提交的文件，已归档或已更新项保留。推荐可按来源取消、恢复；取消不删除标签字典或已采纳绑定。人工取消和移除决定会被记住，避免下次匹配自动补回。

异常在单文件内提示并可重试；失败、未参与计算不能被当作无标签。确认前文件或标签定义变化时重新匹配该文件，保留正式结果；仅修改展示开关不使结果失效。

无标签及未处理推荐不阻止确认和归档，不再勾选“无适用标签”。未处理推荐随归档内容、版本及页码保留。同步弹窗提示耗时随文件数、页数增加且算力消耗较大，确认按钮明确本次选中的文件数量。
