#### 6.1 功能目标

维护平台的"维度—取值"标签字典与可配置派生规则：分类维度承载业务标签，枚举字段承载内容固定属性（用户可见范围、推广性质、内容渠道）；规则统一以"触发一组取值 → 产出一组取值"管理，支持影响面评估与重算；提供全入口名称/别名查重、推荐治理与三表 Excel 交换，并保留创建新版本式的批量标签同步。

#### 6.2 适用场景

维护维度与取值、配置与试算派生规则、Excel 导入导出、审核推荐标签；以及更新字典或规则后，对存量正式内容批量同步并归档生成新版本。

#### 6.3 业务规则

##### （1）维度与取值

1. **两层结构**：维度（根）+ 取值（叶）。不提供第三级；一个取值只能属于一个维度，**不支持跨维度移动**（需要换维度时停用后新建）。
2. **两类维度**：
   - **分类维度**：值是业务标签，授权用户可增删改名（内容类型、内容主题、产品、疾病领域、药物分类、治疗方案）。
   - **枚举字段**：值是内容固定属性，**可新增**（当前预置用户可见范围、推广性质、内容渠道三项）；取值可维护，但被规则或内容引用时不提供直接删除，只能停用。
3. **维度属性**：`基数`（单值/多值）、`作用域`（材料级/页级/两者）、`AI 匹配`（闭集/开放/不参与）、`合并策略`（并集/优先级）、`填充方式`（人工/规则/两者）、`兜底值`、`允许人工修改`、`排序`、`启用`、`对外展示`。
4. **取值属性**：名称、别名、排序、启用、对外展示、仅规则产生。
5. **没有"系统预置锁定"的取值**：任何取值都可改名、调序、停用；所有写操作记审计（操作人、前后值、影响份数）。
6. **删除**：不提供物理删除。被规则或内容引用的取值只能停用；停用后不再产生新绑定，已有绑定保留并标`已停用`。

##### （2）派生规则

1. **结构**：`触发（维度 + 一组取值 + 任一/全部 + 整份/同页） → 结果（维度 + 一组取值）`，附优先级、来源（初始预置/业务自建）、启停。
2. **求值输入**：只读取 `AI` 与 `人工` 产生的取值，以及人工设置过的字段；**规则产物不参与任何规则的触发**，因此规则之间不存在链式触发与循环。
3. **合并**：
   - 目标维度 `合并策略 = 并集`：所有命中规则的结果取并集（受众集合、渠道等）。
   - 目标维度 `合并策略 = 优先级`：按 `优先级` 升序取第一条命中规则的结果；优先级相同按创建顺序稳定。
4. **人工优先**：目标维度 `允许人工修改 = 是` 且人工设过值时，规则不覆盖，界面给"规则建议 X"提示，可"恢复按规则"。
5. **禁止自派生**：触发维度与目标维度相同不允许保存（规则不读取自身产物，配置了也不会生效）。
6. **落库校验**：结果取值必须启用且未被排除；停用取值不产出。
7. **兜底**：目标字段所有规则均不命中时落兜底值；人工清空字段（记人工）后不再兜底。
8. **生效方式**：保存规则不自动重算存量；界面只显示"待重算 M 份"，由用户显式点击"重算"后生效。重算幂等，只重写规则产物，人工值不动。
9. **停用/删除规则**：已产生的规则产物不自动撤销，提示"需重算后生效"；重算后产物消失，人工值保留。

##### （3）用户可见范围

1. 它是**枚举字段**（多值），取值是受众集合，当前预置`未注册 / 已注册待认证 / 已认证`三项；取值可维护，新增或改名后全部读取点（详情、列表、筛选、导出）自动跟随。
2. **不再存在"All三类用户"这个标签值**：三个受众全选时，展示文案为 `All三类用户`；部分选择按名称顿号连接；空为`未设置`。
3. 取值不控制任何系统权限，仅作投放与展示口径。
4. 人工调整后标记人工，规则不再覆盖；"恢复按规则"清除人工标记并重算。
5. 为空视为`未设置`：归档不阻断；二期发布前校验阻断。

##### （4）名称与别名查重

1. **归一化**：`NFKC` + 去首尾空格 + 转小写后比较（全角/半角、大小写差异视为同名）。
2. **同一维度内**（硬阻断）：
   - 取值名称与本维度其他取值名称相同；
   - 别名与本维度其他取值的名称或别名相同；
   - 别名与自身名称相同，或别名列表内部重复。
3. **跨维度允许同名同别名**：命名空间按维度隔离（如"治疗"可同时存在于内容主题与治疗方案）。
4. **相似提醒**：同级编辑距离相似度 ≥ `0.7` 时列出最多 `5` 项候选，可`返回修改`或`仍然保存`。
5. **Excel 导入**：同文件内重复、与库内冲突均为该行错误，整批阻断。

##### （5）Excel 三表交换

1. 工作表固定为`维度` / `取值` / `规则`，表头固定，禁含公式，布尔列填`是/否`。
2. `维度`：ID、维度名称、类型、基数、作用域、AI 匹配、合并策略、填充方式、兜底值、允许人工修改、启用、对外展示。
3. `取值`：ID、维度ID、维度名称、取值、别名、排序、仅规则产生、启用、对外展示。
4. `规则`：ID、规则名称、触发维度、触发取值、匹配方式、目标维度、结果取值、优先级、来源、启用。
5. **引用校验**：规则按名称引用维度与取值，必须存在；同批新建的取值可被后续规则引用；兜底值写在后面的取值表里也能解析。
6. **导入语义**：只做新增与更新，不做删除；有错误行整批不入库；相似项需逐行处理。
7. 旧的双表模板不再接受，导入失败提示中直接给"下载模板"入口。

##### （6）同步最新标签到文件（保留原文，改三处）

1. 字典口径：**AI 匹配 ≠ 不参与且非"仅规则产生"** 的全部启用取值。
2. 100% 保留原有 `AI` / `人工` 绑定，只在未绑定且无排除记录的位置补充 `AI`，并按**当前规则**重算字段值与规则产物。
3. 归档与新建版本规则不变。
4. **批次期间规则变更**：建议批次启动时冻结规则快照，整批使用同一份规则，避免同批口径不一致（当前原型取最新规则，见第 5 节）。

##### （8）关键状态

- **维度**：`启用` / `已停用`（停用后不产出、不参与 AI、不可新增绑定，已有绑定保留）。
- **取值**：`启用` / `已停用` / `仅规则产生`（可叠加）。
- **规则**：`启用` / `已停用`；来源 `初始预置` / `业务自建`。
- **字段值**：`规则推导` / `人工设置` / `未设置`。
- **规则产物**：存在 / 已撤销（重算后）/ 已排除（人工移除后）。

- 导入审计记录三维度计数：`维度 X / 取值 Y / 规则 Z`。
- 重算审计记录影响份数与实际变更份数。

#### 6.4 整体流程

1. 在`维度与值`维护维度与取值（字段取值同样可维护），在`派生规则`配置触发与结果，用"试算"验证一份内容的结果。

4. 需要批量给存量内容补值时，发起"同步最新标签到文件"→ 模块四确认 → 归档生成新版本。

| 两级标签 / 一级分类 / 二级标签 | 维度 / 取值 | 结构没变两层，但语义是"维度—取值" |
| 写死集合 / 系统预置锁定 | （删除） | 改为"取值可维护 + 被引用时仅停用 + 全量审计" |
| 不参与 AI 匹配集合 | 维度 `AI 匹配 = 不参与`；取值 `仅规则产生` | 两个不同粒度，别再混用 |
| 派生标签 / 自动派生 | 规则产物 | 来源为 `规则`，带 `ruleId` |
| 用户可见范围（标签） | 用户可见范围（字段，受众集合） | 三选一 → 多选集合 |
| 多档命中取最宽 | 并集 | 集合合并的自然结果，不再有"档位顺序"特例 |
| 双工作表 `.xlsx` | 三表：维度 / 取值 / 规则 | 旧模板不再兼容 |
| 标签更新批次"两级标签" | "各维度取值与字段值" | 4.3(1) 表格 |

## 4. 必须补充的边界场景

> 建议放在模块六 6.3 之后新增一节"6.3(10) 边界与异常"，或在各条规则后就近补。以下每条都可直接作为验收用例。

### 4.1 命名与别名

| 场景 | 系统行为 | 提示 | 审计 |
| --- | --- | --- | --- |
| 同维度新增取值与已有名称全半角/大小写不同 | 归一化后视为同名，阻断 | "该层级下已有同名标签" | 失败记录 |
| 两个取值的别名相同 | 阻断，指出冲突的取值名 | "该层级下已有同名标签或别名：{名称}" | 失败记录 |
| 别名与自身名称相同 / 别名列表内部重复 | 阻断 | "别名不能重复或与标签名称相同" | 失败记录 |
| 别名与另一个取值的名称相同 | 阻断（别名也占用名称空间） | 同上 | 失败记录 |
| 两个维度下有同名取值（如"治疗"） | 允许，命名空间按维度隔离 | 无 | 正常记录 |
| 别名留空或只有分隔符 | 视为未填别名，不报错 | 无 | 正常记录 |
| 导入时同一文件内两行同名/同别名 | 该行报错，整批不入库 | "{工作表} 第 N 行：..." | 失败记录 |
| 改名后已有绑定与排除记忆 | 绑定按 ID 保留，展示即时更新；排除记忆按 ID 不受影响 | 无 | 记录前后名 |

### 4.2 规则冲突

| 场景 | 系统行为 | 提示 |
| --- | --- | --- |
| 同一字段两条规则同时命中，字段为`并集` | 结果取并集（如受众 A+B） | 无 |
| 同一字段两条规则同时命中，字段为`优先级` | 取优先级数字最小的一条；相同则取创建更早的一条 | 列表可见优先级，建议业务给不同值 |
| 两条规则结果互斥（单值字段产出不同值） | 按优先级择一，不静默合并 | 试算里展示"最终生效值" |
| 规则与人工值冲突 | 人工优先；规则不覆盖 | 详情页"规则建议：X"，可"恢复按规则" |
| 规则与 AI 冲突（目标为分类维度且单值） | 人工 > 规则 > AI；同级保留先到 | 无 |
| 规则 A 的产物作为规则 B 的触发 | **不会发生**：规则只读取 AI/人工，不读规则产物 | 无 |
| 触发维度 = 目标维度 | 保存阻断 | "触发维度与目标维度不能相同" |
| 目标取值已停用 | 该取值不产出，其余结果正常 | 规则列表标"部分结果不可用" |
| 触发取值已停用但内容仍绑定 | 仍视为命中（判断依据是绑定存在），保持历史一致 | 无 |
| 删除/停用规则后 | 产物保留，提示需重算；重算后撤销 | "已停用，重算后生效" |
| 两条规则优先级相同 | 按创建顺序稳定取第一条 | 建议提示"优先级相同，按创建顺序生效" |

### 4.3 启停互相影响

| 操作 | 已有绑定 | AI 打标 | 规则触发 | 规则产出 | 人工添加 | 恢复后 |
| --- | --- | --- | --- | --- | --- | --- |
| 停用取值 | 保留并标`已停用` | 不再命中 | 仍可作触发（绑定还在） | 作为结果时不产出 | 不可选 | 启用即可用；规则需重算补回 |
| 停用维度（分类） | 保留 | 该维度整体不进 AI | 作为触发时不再命中（新内容无绑定） | 作为目标时不产出 | 不可选 | 启用 + 重算 / 重新打标 |
| 停用字段维度 | 字段值保留只读展示 | 本就不参与 | 不再求值 | 不产出 | — | 启用 + 重算 |
| 停用规则 | 产物保留 | 不受影响 | 不再命中 | 不再新增/更新 | 不受影响 | 启用 + 重算 |
| 停用 + 立即重算 | 规则产物撤销，人工值保留 | — | — | — | — | 需再重算恢复 |
| 维度停用但其取值被人为启用 | 维度停用优先，取值不可用 | 不参与 | — | — | 不可选 | — |

### 4.4 人工、排除与兜底

| 场景 | 系统行为 |
| --- | --- |
| 人工移除规则产物 | 记`取值 ID + 位置`排除；之后重算/重打标都不补回；人工重新添加解除 |
| 人工把字段改成空 | 标记人工，规则不再覆盖，**兜底也不生效**（视为人工选择"未设置"） |
| 人工只改受众中的一项 | 整个字段标记人工（不是逐项），其余项保持当前值 |
| "恢复按规则" | 清除人工标记 → 按当前规则重算，若都不命中则落兜底 |
| 规则建议与人工一致 | 不显示冲突提示，仅标"人工设置" |
| 取值改名后排除记忆 | 按 ID 命中，仍然有效 |

### 4.5 数据、并发与口径

| 场景 | 系统行为 | 待定 |
| --- | --- | --- |
| 重算重复执行 | 幂等：先清规则产物再重算，结果不变 | — |
| 重算范围 | 只处理正式内容`当前版本`；历史版本只读、不重算 | 是否要重算待归档批次 |
| 影响面统计口径 | 按当前版本触发条件命中数；不含历史版本、不含批次暂存 | — |
| 批次进行中修改规则 | 原型取最新规则 | **建议冻结批次规则快照** |
| 导入时规则引用了被跳过的取值行 | 规则行报错，整批阻断 | — |
| 导入同一行既改维度类型又改基数 | 允许，按行内最终值生效 | 是否禁止改类型 |
| 维度下所有取值都停用 | 该维度视为空，AI 不命中，规则不产出 | 是否告警 |
| 内容没有任何取值但字段有兜底 | 落兜底值（如可见范围落`已认证`） | 兜底档是否应为"最保守" |
| 字段值为空 | 归档放行；二期发布前阻断 | 一期是否要在确认页提示 |
| 导出包结构变化 | `tags` 增加 `dimension/ruleId`，新增 `fields` | 下游解析需同步 |
