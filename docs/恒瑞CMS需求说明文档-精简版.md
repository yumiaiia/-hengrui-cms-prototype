原型：https://www.lvdian-prototype.xyz

## 一、全局规范

### 1.1 阶段范围与整体流程

- **一期范围**：登录认证与通知（模块一）、工作台（模块二）、上传暂存（模块三）、待归档确认（模块四）、正式内容库与导出（模块五）、标签与派生规则管理（模块六）、公众号采集（模块八）、系统管理（模块九）、操作审计（模块十）。
- **二期范围**：模块七`发布管理`整章、工作台`发布失败`卡片与`近期发布`侧栏、内容库列表与详情发布列/按钮、系统管理`发布管理`权限项、审计`发布管理`筛选项及发布类通知事件（一期均隐藏/不触发）。
- **端到端主流程**：企微 SSO 按纯数字`工号`登录 → 批量/新版本上传至`待归档`（异步提取正文、`AI` 打标与单层规则推导），或公众号自动采集直入`已归档`（`V1.0` 自动打标与推导） → 待归档工作台处理异常、核对标签属性并逐份确认后按份硬校验归档（生成 `V1.0` / `V{N+1}.0`） → 正式库检索、在线编辑、作废或导出 `.zip` 包；标签管理支持维度/取值/规则维护（即改即重算）与`标签更新`批量同步 → 二期对合规未过期`正常`当前版本排期发布。

### 1.2 核心概念与全系统统一约定

- **两层标签体系**：严格为**维度（根）→ 取值（叶）**两层，不设第三级；所有维度恒定启用、禁止停用；维度`类型`创建后不可修改；取值支持别名、排序（`order`）与`仅规则产生`属性，**仅可停用、不可删除**且不可跨维度移动。
  1. **分类维度**（业务语义标签，如内容类型/形式/主题、产品、疾病领域、药物分类、治疗方案）：支持配置`基数`（`单值/多值`）、`作用域`（`材料级/页级/两者`，Excel 写`材料级与页级`）、`AI 匹配`（`闭集/开放/不参与`）、`合并策略`（`并集/优先级`，`单值`锁定`优先级`）。
  2. **枚举字段**（固定属性，预置`用户可见范围`、`推广性质`、`内容渠道`，Excel`类型`写`字段`）：可新增；界面隐藏`AI 匹配`与`作用域`开关，保存与导入固定 **`AI 匹配 = 不参与`** 且 **`作用域 = 材料级`**；支持`兜底值`与`允许人工修改`（`是/否`）。
- **标签三态来源与同构呈现**：内容侧分类维度与枚举字段统一以“维度分组 + 来源着色芯片”呈现，芯片内不展示来源文字，仅以颜色和悬停说明区分：**`AI`（蓝）**、**`人工`（琥珀）**、**`规则`（紫，附 `ruleId`）**；枚举字段未命中规则且无人工标记时应用`兜底值`，归属`按规则推导`态，沿用紫色芯片但悬停提示“未命中规则，应用默认兜底值”（导出 `source: "规则"` 且 `fallback: true`）。
- **单层派生规则铁律**：规则结构为`触发（维度 + 取值集 + 任一/全部） → 结果（维度 + 取值集）`，触发范围统一为**整份内容当前版本并集**。规则引擎**仅读取 `AI`/`人工` 分类绑定与带`人工标记`的枚举字段**，严禁读取`规则`产物或`兜底值`，天然 1 跳求值无循环；保存与导入硬阻断`触发维度 = 目标维度`、`仅规则产生`取值作触发，以及`允许人工修改 = 否`的枚举字段作触发。
- **核心业务状态枚举**：
  - `生命周期`：`正常`、`已作废`（不可恢复，全版本只读）。
  - `审批状态`：`已登记`（选`需要登记`并完成登记）、`免登记`（选`不需要登记`）、`待补充`（如公众号采集入库初始态）。
  - `有效状态`（北京时间自然日，`剩余天数 = 有效期 - 当天`）：`未设置`（空）、`生效中`（`> 30` 天）、`即将过期`（`0 ~ 30` 天含当天）、`已过期`（`< 0` 天）。

### 1.3 全局角色、权限与范围总则

- 内置唯一`超级管理员`（系统保留，禁改/禁停/禁删/禁分配）；其余为`自建角色`。写操作须同时满足：`账号启用 + 开启模块菜单 + 开启对应操作权限`（仅开菜单为只读；勾操作自动开菜单；关菜单清空操作；`系统管理`与`操作审计`各自菜单与唯一操作同开同关）。
- **`用户可见范围`等枚举字段仅作属性记录与展示，不参与任何权限判定与发布准入拦截**。

## 二、功能模块需求

### 模块一：登录认证与全局通知框架

- **企微 SSO 登录**：仅支持企业微信单点登录，无账号密码页。回调提取`工号`（去首尾空格、`1~64` 位纯数字 `0-9`、保留前导零），精确匹配唯一`已启用 + 有效角色`账号后进入`工作台`（无权限进首个已授权菜单）。失败就地拦截提示（票据无效、未匹配工号、账号停用、无菜单权限），不记审计。
- **会话状态与保护**：`未登录`、`已登录`、`强制下线`（账号被停用或全部菜单被收回时立即销毁会话退回登录页）。上传页有未提交内容离开触发二次确认；文件上传落盘中阻断路由切换。
- **全局导航与通知交互**：`内容库`常驻徽标仅统计`正常`正式内容总数；`发布管理`一期隐藏。右上角通知中心按时间倒序（当年 `MM-DD HH:mm`，跨年 `YYYY-MM-DD HH:mm`），站内同接收人同标题同跳转路由的未读通知自动覆盖更新并置顶。完整通知事件见第三章。

### 模块二：工作台

- **待确认结果横幅**（具备`上传内容`或`维护标签库与推荐 + 维护内容标签`可见，三项互斥）：`待确认结果 {N} 份`（异步完成、未归档、未取消且非`归档需处理`）、`{M} 份处理中`（含`排队中`）、`{K} 份异常需处理`（`解析/匹配失败`或`归档需处理`）。
- **正式内容待处理列表**（可见`正常`当前版本，每页 6 条，同内容合并一行按最高优先级升序 + 更新时间倒序）：`0-已过期`（详情审批抽屉） > `1-审批信息待补充`（详情审批抽屉） > `2-标签待核对`（内容详情） > `3-即将过期`（详情审批抽屉）。支持按问题分类卡片筛选及点击复位。
- **二期发布概览**：一期隐藏；二期展示`发布失败`卡片与最近 4 条`待发布`排期侧栏。

### 模块三：内容上传与暂存登记

- **双入口与去重限制**：
  1. **批量上传**（上限 50 份，文件/链接混传）：同批禁止哈希相同文件或规范化后相同公开链接；按哈希或链接在`正常`内容及其历史版本匹配（优先`当前版本`，多内容历史命中按最近更新时间倒序取唯一目标），命中规划为`创建新版本`（`V{N+1}.0`），未命中为`新增内容`（`V1.0`）。**同批不同文件/链接若命中同一内容的不同历史版本，同样标记`需处理`并阻断提交**。
  2. **指定内容上传新版本**：目标须为`正常`，锁定基准版本号，**每次仅限 1 个文件或 1 条公开链接**（重选即替换，多选拦截）。
- **文件规格与素材继承**：支持 `PDF/PPT/Word/HTML/图片/视频`（`> 0 B` 且 `<= 1 GB`）；公开链接上传页仅同步校验无凭据 `http/https` 格式与去重，网页抓取与正文提取归入异步解析。所有新上传初始`摘要`均为空。创建新版本提交暂存时，**静默继承上一版素材**：未编辑补充视频区则继承上一版全部视频（`0~3` 个，`.mp4/.webm/.mov` 单 `<= 1 GB`），手动增改则以本次列表为准；封面/缩略图（`<= 10 MB`）未重设或未显式清除则继承上一版；**不带入原审批截图，亦不预填原编号与有效期**（须新传或显式复用）。
- **审批编号解析、OCR 与辅助打标**：整批共用`需要登记`或`不需要登记`（需`免登记审批`权限，选免登记时上传页无有效期输入框，入库后默认`未设置`，可至模块五补填）。`NFKC` 归一后**从右向左**解析双结构编号（末段 `-YYYY-MM` 或 `-YYMM` + 倒数第二段 5 位流水号），自动填入末段自然月最后一天为`审批有效期`（无法解析则转手填）。上传 1 张审批截图（`<= 20 MB`）自动整图 OCR，存在差异或未识别时二次确认保存，并存储后台辅助字段（不展示输入框）：
  - `申请日期 + 申请类型`（推广 `+2` 年 / 非推广 `+3` 年月末）或`滚动年度`（年份）与末段有效期不一致时，展示非阻断轻量核对提示。
  - 异步打标读取 OCR 的`申请部门`、`疾病领域`、`产品`，仅匹配`AI 匹配 != 不参与`、已启用、非`仅规则产生`且含材料级的分类维度（`闭集`只命中已有、`开放`新词入推荐池），命中写入材料级记`AI`，随后执行一次单层派生规则计算。
- **状态与流程**：同步态（`待提交`、`需处理`、`已暂存`） → 跳转模块四进入异步态（`排队中`、`处理中`、`待确认`、`解析失败`）。暂存提交记`提交上传批次`审计（含 OCR 差异人工核对时注明并触发预警）。

### 模块四：待归档管理与结果确认

- **两类批次统一与必要差异**：`上传归档`与`标签更新`共用队列筛选（`全部文件 / 待确认 / 处理中[含排队中] / 已确认 / 异常/失败[含解析/匹配失败与归档需处理] / 已归档 / 已取消`）、单文件无前置硬校验确认（零标签或字段空均放行）、确认自动失效（改信息/素材/标签/字段/推荐或重试退回`待确认`）、按份硬校验归档与取消机制（终态`已归档`或`已取消`；全结束消解未读通知）。差异仅四点：
  1. 发起与权限：`上传归档`由内容库发起（需`上传内容`）；`标签更新`由标签管理发起（需`维护标签库与推荐 + 维护内容标签`，全局限 1 批在途）。
  2. 默认页签：前者默认`内容信息与素材`，后者默认`打标结果`。
  3. 维护范围与并发继承：前者可改标题/摘要/封面/缩略图/补充视频（源文件与审批只读）；后者非标签信息与审批快照在确认页全只读，且**归档生成 `V{N+1}.0` 事务提交时实时继承目标当前最新 `V{N}.0` 的实时非标签数据与审批**，防止覆盖在途期间他人原地修改。
  4. 变化标注：仅`标签更新`以基准版本为对照标注绿色`新增`、底部`本次移除`虚线删除线分组及标题`+N −M`汇总。
- **`标签更新`批次容错口径**：匹配与核对阶段不校验内容快照差异，也不因标签库编辑、改名或停用而中断；批次发起时记录基准版本号并冻结派生规则快照（`ruleSnapshot`），**标签库本身不冻结**，匹配与展示始终按当前标签库执行（改名即时更新，基准版既有停用绑定保留并标`已停用`且归档豁免，新匹配不产出）。
- **同构确认交互**：材料级将枚举字段与分类标签并入同一分组列表（待归档页枚举字段仅显已选值，通过`添加材料标签`统一弹窗增补；点击芯片 `×` 移除至空即为“人工未设置”，保留`人工标记`且不落兜底，组头`恢复`按钮清除标记回到规则推导）；切换`页级标签`隐藏所有枚举字段与`仅材料级`维度。
- **按份硬校验与失败流转**：点击批量归档逐份校验：① 异步解析/匹配`完成`；② 标题非空且文件/视频/截图可读；③ 绑定位置合法（字段与规则产物仅材料级）、页码在 `1..总页数`、单值同位置不超过 1 个、当次新增绑定须`启用`且 `AI/人工` 新增不得为`仅规则产生`（`规则`新增允许`仅规则产生`，历史停用继承豁免，改名/改别名/调序不阻断）；④ 审批凭证齐全或仍保有免登记权限；⑤ 建新版本项满足目标`生命周期 = 正常`且`当前版本号 = 批次基准版本号`。**校验通过立即入库为`已归档`（`V1.0` 或 `V{N+1}.0`）；未通过项自动退回`待确认`并附`归档需处理`标记及原因，修复或重确认后可再提交**，消除死锁。单文件确认不记审计不发通知；修改暂存、归档、重试、取消均记`内容库`审计。

### 模块五：正式内容库、详情与导出管理

- **列表与检索**：每页 8 条，默认`内容状态 = 正常`（已归档无解析中/失败态）。`标签`列以紧凑芯片合并展示材料级分类标签与枚举字段（前 2 枚 + `+` 快捷编辑，按来源着色，`未设置`为中性灰；`用户可见范围`全选 `K>=1` 项展示`全部用户`，部分选展示单项或`N 类受众`）。支持搜索（标题/编号/审批号/维护人姓名/工号）、枚举字段筛选（含`未设置`）与维度筛选（`材料标签`与`页级标签`均同维 `OR`、跨维 `AND`，页级要求跨维同页命中）。
- **版本与编辑边界**：支持切换 `V1.0 .. V{current}.0`。仅`正常`的`当前版本`可编辑；所有`历史版本`与`已作废`严格只读（可预览正文/视频、下载与导出快照）。
  - **编辑信息与审批**：原地保存不升版。更新审批复用双结构编号解析与 OCR 核对，OCR 自动补充匹配新命中的 `AI` 材料级分类取值（单值已有绑定不覆盖，开放集新词入推荐池并遵排除记忆，既有 `AI` 绑定保留），并重算未人工锁定的派生结果。
  - **详情摘要与同构抽屉**：头部摘要汇总材料级标签与枚举字段（`用户可见范围` `K>=1` 全选显`All三类用户`/`全部 K 类用户`，部分选顿号拼接，`K=0` 或空显`未设置`）。材料标签抽屉中枚举字段**直接平铺已选与未选虚线芯片**点击即切换（与待归档弹窗交互有意区分），人工改动置整字段`人工标记`并支持`恢复`；分类维度展示已绑定芯片并经添加入口增删，移除或单值替换写入`取值 ID + 位置`排除记忆并实时重算单层规则。分页阅读器支持缩略图、正文画布与右栏页级标签双向联动。
- **作废与导出**：列表/详情二次确认作废（自动过滤`已作废`），即刻不可恢复。公开链接无原文件提示不可下载，导出包生成 `content.html`；`.zip` 包内含 `manifest.json` 与 `{CMS_Code}/V{N}.0/`（`original/`、`metadata.json`、`media/`、`approval/`）。`metadata.json` 中 `fields` 数组为权威字段契约（`{ dimension, values, source: "人工" | "规则", ruleIds?, fallback? }`），`tags` 数组含 `{ name, dimension, origin, ruleId?, page? }`，顶层 `visibility / visibilitySource` 仅保留作历史兼容镜像；历史导出二次下载实时重验内容可见性与审批截图权限。

### 模块六：标签维度与派生规则管理

- **维度与取值约束**：严禁停用维度、严禁物理删除取值、严禁跨维度移动、维度`类型`创建后不可改。同维度内名称与别名经 `NFKC + 去空格 + 小写` 归一化后硬阻断重名（跨维度允许），相似度 `>= 0.7` 提示最多 5 项；改名按 `valueId` 保持绑定、规则与排除记忆。存在多结果取值的规则引用某维度时，禁止将其由`多值`改为`单值`；分类维度作用域收紧为`材料级`时，存量页级绑定保留只读且归档豁免。
- **派生规则与冲突收敛**：
  - `合并策略`：`并集`（全部命中规则结果去重合并）或`优先级`（仅取优先级数字最小 1 条命中规则结果；若该条结果全停用，视为无有效结果不顺延，枚举字段未锁定则落`兜底值`或空）。**同目标维度下优先级必填且严格唯一**。
  - **单值与人工优先**：单位置单值分类维度严格遵循 **`人工 > 规则 > AI`**（规则可替换 `AI` 不写排除记忆），同来源按 `order` 升序（相同按名称字典序）取第 1 个；多值分类维度人工与规则共存，人工删除规则产物按 `valueId + 材料级` 记排除记忆；枚举字段走整字段`人工标记`（含人工清空），永不被规则或兜底覆盖，点`恢复`回到规则推导。
  - **即时重算**：规则增删改启停、取值启停、**维度修改`兜底值`或`合并策略`**、以及 Excel 导入提交后，立即对全系统`正常`当前版本同步幂等重算（保留人工绑定、已有`人工`多值与排除记忆）；`多值`改`单值`重算时不删既有多个`人工`绑定，仅在下次人工编辑时收敛。规则编辑支持任选正式内容“试算”（不写库）。
- **停用影响与推荐治理**：停用取值保留存量标注`已停用`并禁止新增；作规则触发时存量仍命中（停用前提示受影响规则数），作结果时标记规则`结果部分不可用/结果不可用`并立即重算撤回，作`兜底值`时弹窗提示并运行时跳过；重新启用立即重算补回。`闭集`库外新词静默丢弃；`开放`写入推荐池（跳过排除记忆），由`开放`切`闭集/不参与`后停止新增推荐但保留历史待处理项。`由推荐新建取值`需`维护标签库与推荐`，直接`采纳/恢复推荐标签`须同时具备`维护内容标签`。
- **三表 Excel 交换**：固定工作表 **`维度` / `取值` / `规则`**，禁公式，拒收旧双表。校验类型不可变、多结果规则引用禁改`单值`、枚举字段非默认 `AI/作用域` 报错、禁自派生/`仅规则产生`或`允许人工修改 = 否`枚举字段作触发、单值维度锁定`优先级`且单规则单结果、同目标维度优先级唯一；任意错行整批阻断。
- **同步最新标签到文件**：具备`维护标签库与推荐 + 维护内容标签`者针对`正常`当前版本发起`标签更新`批次（全局限 1 批在途）。发起时记录基准版本号并冻结全量派生规则快照（`ruleSnapshot`），**不冻结标签库**；后台 100% 保留既有 `AI/人工` 绑定，仅在未绑定且无排除记录位置按当前标签库字典补充新命中 `AI` 标签，再用冻结规则快照重算，交由模块四核对升版。

### 模块七：发布管理（二期功能）

- **准入硬条件**：`生命周期 = 正常`、`审批状态 != 待补充`、`有效期`非空且未`已过期`（**不校验`用户可见范围`等枚举字段**）。
- **草稿、提交与快照**：`草稿`可编辑且不锁快照；整批`提交发布`要求`拟发布时间`晚于当前且自然日 `<= 有效期`、发布标题/封面/缩略图齐备（修改不反写内容库），按份生成`待发布`并锁定 `V{N}.0` 静态快照（含 `tags` 与 `fields`）。内容库后续改版不影响已提交快照（提示`已有 V{current}.0` 并支持基于新版新建）。下游回传三端预览及`已发布 / 发布失败`（不记审计，失败计入工作台卡片并通知）。

### 模块八：公众号采集

- 一期展示预设公众号（`自免医时空`、`爱医慢时空`、`爱医时空`、`爱眼医时空`）中`采集成功`、正文非空且关联内容可见的文章，支持筛选、搜索、只读查阅首次采集正文快照（不随内容版本变化）及复制无凭据 URL。
- 后台采集直入生成正式内容 `V1.0` 时自动完成 `AI` 打标与单层派生规则计算；仅关联正式内容**`生命周期 = 正常`且审批为`待补充`**时，对具备`编辑内容与审批`者展示`补充审批`入口（`已作废`隐藏）。

### 模块九：系统管理（用户与角色权限）

- **账号与工号**：`工号`创建必填（`1~64` 位 `0-9` 纯数字，保留前导零），全库含已停用账号严格唯一，**创建后不可修改**；`超级管理员`账号与角色系统保留禁改/禁停/禁删/禁分配；禁停自身或撤自身`系统管理`权限；有关联账号的角色禁删。
- **导入导出与联动**：`用户导入模板.xlsx`（`用户`表 + `可分配角色`参考表）要求`工号`列为文本格式 `@`，禁公式，有错行阻断并支持下载错误明细；导出 `用户列表.xlsx`。角色权限严格遵守“仅开菜单只读、勾操作自动开菜单、关菜单清空操作、`系统管理`与`操作审计`同开同关”。

### 模块十：操作审计

- **纳入与排除**：只读记录全系统显式人工写入提交（每页 10 条，按操作时间倒序，支持默认近 7 天及内容详情全版本穿透检索），保存姓名/工号快照、时间、模块、标准操作、说明（`<= 70` 字符）与结果（`成功/部分成功/失败/未记录`）。查询/导出/下载、登录退出/`强制下线`、通知已读、**待归档单文件确认**及一切后台自动任务/规则重算/通知推送均不记审计。
- **模块归属与合并口径**：待归档修改暂存、两类批次在待归档的`归档已确认内容`/`重试失败任务`/`取消批次`统一记入`内容库`；OCR 差异人工核对合并记入`提交上传批次`或`更新当前版本审批信息`；标签配置或维度`兜底值/合并策略`修改引发的同步重算在对应`标签管理`操作说明中附`重算影响 N 份`。

### 3.1 投递与消解总则

- **双通道**：站内通知中心（当年 `MM-DD HH:mm`，跨年 `YYYY-MM-DD HH:mm`）与企微应用消息；通知推送不记审计。
