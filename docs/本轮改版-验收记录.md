## 2. 浏览器流程验收

| 场景 | 验证结果 |
| --- | --- |
| 批量上传 PDF、PPT、Word 示例 | 文件暂存后进入解析与确认页；处理完成前正式内容数量不增加 |
| 材料及页级标签核对 | 可添加、移除指定位置标签；逐份确认后批量归档，支持先归档一份、再继续其他文件 |
| 刷新继续处理 | 批次、处理结果和确认记录保留；已归档项可查看正式内容 |
| 登记审批后归档 | 使用一致审批示例完成登记；正式详情显示有效期、上传时间、确认人及时间、归档时间 |
| 提交后固定原文件和审批 | 确认页移除更换源文件、下载核对和修改审批入口；数据操作接口同步阻止相关字段变更 |
| 手动新增相似标签 | 候选仅展示名称、分类、启停状态；只有“返回修改 / 仍然创建”，无候选选择或“使用已有标签”操作 |
| Excel 标签导入 | 有相似候选时确认按钮禁用；逐行选择“仍然入库”后可导入 |
| 用户导入错误 | 重复工号显示原文件行号和错误原因，整批确认按钮禁用 |
| 用户导入成功 | 真实 .xlsx 导入账号成功，账号默认启用，工号 `000099` 保留前导零 |
| 用户筛选导出 | 搜索指定工号后仅导出匹配账号；读取实际下载文件，确认只有一行数据、工号为文本 `000099`、列格式为 `@` |
| 审计简表 | 仅查询用户写入操作，按模块筛选；显示时间、操作人 / 工号、模块、操作、简短说明及结果，不显示字段差异或详情 |
| 两个页面的版本冲突 | 后打开页面先归档后，原页面同步看到新版本；旧目标提交被阻止，重新核对并确认后才能归档 |
| 视觉检查 | 检查文件队列与页签工作区、只读相似提示和审计简表；文档预览采用固定高度滚动，保留固定归档栏 |

### 本次确认交互与视频补充复验

- 上传两份独立 PDF，为第一份设置不同的封面、缩略图，并上传实际可播放的 WebM 视频；第二份保持未设置素材。
- 提交后查看第一份的独立展示素材和视频播放情况；确认页不存在更换源文件、下载源文件核对、修改审批和成功任务重跑操作。
- 逐份在“打标结果”核对材料标签和第 2 页标签；“确认本文件并查看下一份”进入第二份，并回到文件标题。
- 第二份显示其自身空素材状态；第一份的素材不会被批量应用。统一归档后在正式内容详情继续查看素材及视频。
- 源文件和审批信息的锁定、视频归档快照、处理中限制修改、成功任务禁止重试，以及继承封面在确认前可见、主动清除后不恢复，均纳入自动化验证。

### 相似提醒与审计精简复验

### 标签重新匹配与取消复验

- 在“同步最新标签到文件”弹窗中按 CMS 编号搜索并勾选内容，进入与上传确认页共用的标签更新批次；默认打开打标结果，只显示完整材料、页级标签，没有增删建议或分类统计。
- 检查匹配完成后正式内容仍等于原记录；人工补充“临床研究”材料标签，确认后刷新，已确认状态保留。点击“更新已确认的 1 份”后正式标签更新，文件仍为 V1，版本数量仍为 1。
- 推荐来源包含材料、第 2 页、第 3 页；取消第 2 页只影响这一处，可恢复；取消整条待处理推荐后全部来源显示已取消并提供恢复入口。
- 上传 PDF、PPT、Word 三份示例，先取消当前文件，再取消剩余两份；刷新后共 3 份取消、无待执行计时，原正式文件版本仍为 V4、V1、V1；待归档默认列表不再显示该批次。
- 取消标签更新批次后，任务停止且正式内容与开始匹配前完全一致；“包含已结束批次”可查看取消记录。新版本重试不沿用旧版本推荐，已加入回归用例。
- 确认按钮和底部统一更新栏分别固定在不同高度，实际点击验证通过，避免底部栏遮挡单文件确认操作。
- 主设计文档补充 4.6、5.4—5.8；规则梳理文档改为指向主设计的简要结论，避免两套规则并行维护。

### 归档条件与同步范围交互复验

- 上传一份无标签 HTML 和一份带第 2 页未处理推荐的 PPT，均可直接确认并成功归档；页面没有“无适用标签”勾选项，推荐无需先采用或取消。
- 归档后 HTML 的正式标签仍为空；PPT 推荐按正式文件、V2、第 2 页保留为待处理，标签库数量未增加。
- “同步最新标签到文件”默认选择部分文件；搜索标题或编号、格式 / 来源筛选、分页及仅看已选均可使用，筛选和翻页保留跨页勾选。
- 本页全选两页共选中 12 份，取消第一页后保留第二页 6 份；清空选择后确认按钮禁用。全量范围明确显示全部可处理文件数。
- 按编号勾选两份文件后执行，生成的批次仅包含这两份；随后取消任务，未影响正式内容。
- 弹窗提示执行耗时随文件数、页数增加且算力消耗较大；列表独立滚动，筛选、分页、选择数量与确认按钮保持可见。未使用固定分钟数的模拟承诺。

## 3. 实现边界

- 这是可运行的本地原型。文件和结构数据分别保存在 IndexedDB、localStorage；关闭浏览器后任务会在再次打开时恢复处理，不提供服务端常驻执行。
- 解析打标使用模拟任务和本地名称匹配；标签相似按规范化名称的编辑距离计算，阈值为 0.7，不表示完成医学同义判定。
- 用户导入仅批量创建，模板工号列要求文本；不批量修改、停用或覆盖已有账号。
- 新增审计权限独立于编辑、系统管理和截图权限；审计页面不提供编辑、删除、导出。
- 多页面会同步数据，提交前重新读取并校验最新版本；正式产品仍需要服务端事务、并发控制、身份认证与可靠审计留存。
- 既有内容及历史日志保留，审计页仅展示可识别的用户写入记录；未记录的工号、结果和人工确认不补造。
