# 恒瑞 CMS 需求说明文档

## 一、文档说明

本文档描述恒瑞 CMS 已实现功能的产品需求，作为研发实现与评审验收的依据。文中"内容"指一份可归档、可发布的学术素材资产；"材料标签"作用于整份内容，"页级标签"作用于指定页码；"归档"指内容经人工确认后进入正式内容库。

全局约定：

- 时间统一采用北京时间（Asia/Shanghai）。列表展示"月-日 时:分"，审计与详情展示完整日期时间。
- 内容编号格式为 `CMS-` 加 5 位数字（如 `CMS-00018`），由系统在归档时生成，全库递增、不复用。
- 版本号格式为 `V{整数}.0`，同一内容内从 1 递增。
- 所有写操作在提交前重新读取最新数据并再次校验；校验不通过时不写入任何数据，也不产生成功提示。
- 页面提示统一以底部 toast 呈现，展示 4.5 秒，可手动关闭。

## 二、系统概览

### 2.1 功能目标与适用场景

系统面向医药学术内容的上传、核对、归档、标签治理、发布与追溯，解决三类问题：内容入正式库前缺少人工核对、标签重复与失控、批量账号维护与操作追溯困难。

适用角色：内容上传与维护人员、标签维护人员、系统管理员、审计查看人员。

### 2.2 导航结构

| 顺序 | 菜单 | 说明 |
| --- | --- | --- |
| 1 | 工作台 | 待办、待确认归档、发布安排与通知 |
| 2 | 内容库 | 已归档内容、待归档批次、上传入口 |
| 3 | 发布管理 | 二期功能，发布记录与预览 |
| 4 | 公众号采集 | 采集结果查看，只读 |
| 5 | 标签管理 | 标签库、推荐标签、导入导出、同步到文件 |
| 6 | 系统管理 | 用户、角色、用户导入导出 |
| 7 | 操作审计 | 用户写入操作查询，只读 |

菜单按角色的"菜单入口"配置显示，顺序固定。内容详情、上传向导归属"内容库"菜单；发布预览归属"发布管理"菜单。无当前页面菜单权限时展示"没有此页面的访问权限"，并提供返回工作台入口。

### 2.3 权限模型

权限由"菜单入口"与"操作权限"两部分组成。**操作权限仅在所属模块菜单同时开放时生效**；仅有权限而无对应菜单时，该操作不可执行。角色配置页的勾选联动遵循此规则：勾选操作自动开启所属菜单，关闭菜单自动移除该模块全部操作权限。

| 权限 | 所属模块 | 可执行操作 | 数据范围 | 状态限制 |
| --- | --- | --- | --- | --- |
| 上传内容 | 内容库 | 新增内容、上传新版本、处理本人待归档批次、取消本人批次 | 本人创建的批次；可查看全部正式内容 | 目标内容须为"正常"且版本未变化 |
| 编辑内容与审批 | 内容库 | 修改标题摘要素材、登记/更换审批、重新解析、批量修改审批 | 全部正式内容 | 仅当前版本、内容"正常"、非解析中 |
| 维护内容标签 | 内容库 | 增删材料标签与页级标签、采纳已入库推荐、取消/恢复推荐 | 全部正式内容及本人待归档批次 | 仅当前版本、内容"正常" |
| 免登记审批 | 内容库 | 上传或编辑时选择"无需登记审批" | 同上 | 上传/保存/归档时逐次校验 |
| 作废内容 | 内容库 | 单份或批量作废并填原因 | 全部正式内容 | 仅"正常"内容 |
| 下载与导出 | 内容库 | 下载原文件、导出内容资产包、查看导出记录、导出标签库 | 有权限查看的内容 | 无 |
| 查看与下载审批截图 | 内容库 | 查看、下载、随包导出审批截图 | 有权限查看的内容 | 无 |
| 维护标签库与推荐 | 标签管理 | 新增/编辑/启停标签与分类、导入、忽略推荐、发起同步、取消待处理推荐 | 全库标签与推荐 | 无 |
| 创建与提交发布 | 发布管理 | 新建发布、编辑草稿、提交发布 | 有权限查看的内容 | 内容须满足发布校验 |
| 管理账号与角色 | 系统管理 | 创建/编辑/启停账号、创建/编辑/删除角色、导入导出用户 | 全部账号与角色 | 受超级管理员保护规则约束 |
| 查看操作审计 | 操作审计 | 查询用户写入记录 | 全部用户写入记录 | 只读，不可编辑、删除、导出 |

角色规则：

- 超级管理员为内置角色，拥有全部权限与全部菜单，不可修改、不可删除、不可分配给其他账号；对应账号不可修改、不可停用、不可删除。
- 自建角色可创建、编辑、删除。角色名称必填、忽略大小写唯一、不超过 60 字符；至少选择一个菜单入口；含关联账号（含停用账号）的角色不可删除。
- 不能撤销当前登录账号自身的系统管理入口；该调整须由其他管理员完成。
- 停用账号不可登录，其权限即时失效，已保存的内容与历史记录保留。

数据范围：

- 正式内容对拥有"内容库"菜单的角色全员可见，不按创建人隔离。
- 待归档批次仅本人可见，超级管理员可见全部；其他用户不可见他人未归档原文。
- 发布记录随其关联内容可见。
- 审计记录对拥有"查看操作审计"权限的角色全量可见。

### 2.4 核心对象与状态

| 对象 | 关键状态 | 说明 |
| --- | --- | --- |
| 内容资产 | 正常 / 已作废 | 作废后不出现在默认列表，历史版本仍可查看 |
| 版本-解析 | 排队中 / 处理中 / 完成 / 部分失败 / 失败 | 表示文件解析进度 |
| 版本-打标 | 待打标 / 打标中 / 已完成 / 未匹配 / 失败 | "未匹配"表示存在待处理推荐标签 |
| 版本-页级 | 待打标 / 打标中 / 完成 / 失败 / 人工完成 | 仅 PDF、PPT、Word 分页记录 |
| 审批 | 待补充 / 已登记 / 免登记 | 与版本绑定，各版本保留独立快照 |
| 待归档条目 | 处理中 / 待确认 / 已确认 / 已归档 / 已取消 / 需处理 | 归档与取消为终态，互斥 |
| 批次 | 上传归档 / 标签更新；进行中 / 已结束 | 全部条目归档或取消后批次结束 |
| 推荐标签 | 待处理 / 部分处理 / 已采纳 / 已取消 / 已处理 / 已忽略 | 按来源位置独立处理 |
| 发布记录 | 草稿 / 待发布 / 已发布 / 发布失败 | 提交后保存版本快照 |
| 任务 | 解析与打标 / 标签匹配 / 导出 | 后台任务，失败项可重试 |

### 2.5 模块依赖

```text
系统管理（账号/角色/权限）
  └→ 全部模块的可见性与可操作性

内容库 → 上传与归档 → 内容详情 → 发布管理
   │           │
   │           └→ 推荐标签 → 标签管理
   └→ 标签维护 → 同步最新标签到文件 → 待归档批次 → 内容标签更新

工作台 ← 内容状态、待归档批次、发布状态、通知
操作审计 ← 上述全部用户写入操作
```

## 三、登录与身份

**功能目标**：以工号识别唯一身份，按账号角色加载菜单与操作权限。

**适用场景**：用户进入系统、切换演示身份、退出登录。

**业务规则**：

- 一个工号唯一映射一个启用账号；工号比对前去除首尾空格并转为大写。工号缺失或账号停用时不可登录。
- 账号必须关联有效角色，否则登录被拒绝并提示修复角色配置。
- 登录成功后的落地页为角色的第一个菜单；含工作台菜单时进入工作台。
- 退出登录清除当前身份并跳转登录页，不改变任何业务数据。

**字段规则**：

| 字段 | 含义 | 必填 | 格式/取值 | 默认值 | 来源 | 校验提示 |
| --- | --- | --- | --- | --- | --- | --- |
| 工号 | 登录身份 | 是 | 下拉选择已启用账号，展示"姓名 · 工号" | 超级管理员工号 | 用户选择 | 未选择或账号不可用时"请选择已启用且已填写工号的账号。" |

**整体流程**：选择工号 → 校验账号启用与工号唯一 → 校验角色存在 → 写入当前身份 → 跳转落地页。

**关键状态**：未登录 / 已登录；账号启用 / 停用，停用后不可进入。

**结果反馈**：成功提示"已切换为 {姓名} 的本地演示身份。"；角色失效提示"该账号未关联有效角色，请让演示管理员修复角色配置。"；身份未保存提示"演示身份未保存。请检查浏览器存储空间后重试。"

**补充规则**：正式环境以企业统一身份认证替换工号选择，认证通过后按工号匹配账号；未匹配到启用账号时拒绝进入并提示联系管理员，不自动创建账号。

## 四、工作台

**功能目标**：聚合需要处理的内容问题、待确认归档批次与发布安排，作为日常处理入口。

**适用场景**：每日进入系统后查看待办、定位异常内容、继续未完成的归档。

**业务规则**：

- 待办仅统计"正常"内容，按当前版本判定；单份内容可同时命中多个类别。
- 类别与判定：

| 类别 | 判定条件 | 跳转 |
| --- | --- | --- |
| 解析与标签异常 | 解析失败（解析失败、打标失败或任一页解析失败）；或非解析失败且打标状态为"未匹配" | 内容详情 |
| 审批待补充 | 审批方式为"待补充" | 内容详情-审批信息 |
| 30 天内到期或已过期 | 有效期为已过期或 30 个自然日内到期 | 内容详情-审批信息 |

- 排序：先按问题优先级（解析失败、已过期为最高，其次审批待补充，再次标签待核对，最后即将过期），同级按最近更新时间倒序。
- 卡片计数按内容去重，单位为"份内容"；点击卡片筛选该类别，再次点击恢复全部。
- "待确认结果"仅统计当前用户可见批次中仍在进行且解析完成的条目；同时展示解析中数量与异常（解析失败、打标失败、归档失败）数量。
- 发布失败卡与近期发布仅对拥有发布菜单的角色展示；近期发布取"待发布"且已设置时间的记录，按时间升序取前 4 条。

**整体流程**：进入工作台 → 查看卡片计数 → 选择类别 → 打开待办列表 → 进入内容或批次处理。

**关键状态**：工作台不维护独立状态，直接反映内容、批次与发布记录的实时状态；待办随源数据变化即时增减。

**字段规则**：待办行展示内容标题、内容编号、当前版本、全部命中问题标签；分页每页 6 条。

**通知**：顶栏通知面板展示处理完成与需核对事项，包含标题、详情、时间与跳转目标；未读显示红点与数量。点击通知标记已读并跳转对应页面；支持"全部标为已读"。仅展示无指定接收人的公共通知、指定本人的通知与仅管理员可见的通知（后者需"管理账号与角色"权限）。空态"暂时没有通知 / 处理完成和需要核对的事项会显示在这里。"

**结果反馈**：无待办时提示"当前分类暂无待处理内容"；无内容库或发布权限时提示"当前角色暂无内容工作权限"。

**权限控制**：待办与待确认区块需"内容库"菜单；"上传内容"按钮需上传权限；待确认区块对上传权限或"标签库＋内容标签"权限组合开放；发布相关区块需"发布管理"菜单。

## 五、内容库

**功能目标**：提供正式内容与待归档批次的统一检索、筛选、批量操作入口。

**适用场景**：查找内容、按标签或状态筛查、批量作废/审批/导出/发布、继续未完成的归档。

**业务规则**：

- 页签为"已归档"与"待归档"，默认"已归档"；"待归档"内容由待归档列表承载，不与正式内容混排。
- 未归档内容不参与正式内容数量、列表、检索、导出与发布选择。
- 筛选条件变更时回到第 1 页并清空已选；筛选状态按账号在当前会话内保留。
- 材料标签筛选为分类间"且"、分类内"或"；页级标签筛选在材料条件基础上按页匹配，任一页命中即保留。
- 搜索对标题、内容编号、审批编号、维护人姓名与工号做不区分大小写的包含匹配。

**筛选字段**：

| 字段 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 关键词 | 自由输入 | 空 | 占位"搜索标题、内容编号、审批编号或维护人" |
| 内容类型 | 全部类型 / PDF / PPT / Word / 图片 / 视频 / 网页 | 全部类型 | 精确匹配 |
| 有效状态 | 全部 / 生效中 / 即将过期 / 已过期 / 未设置 | 全部 | 按有效期与当前日期计算 |
| 来源 | 全部来源 / 数据中已有来源 | 全部 | "未匹配"来源展示为"有推荐标签" |
| 审批登记 | 全部 / 已登记 / 无需登记 / 待补充 | 全部 | 精确匹配审批方式 |
| 标签识别 | 全部 / 待打标 / 打标中 / 已完成 / 未匹配 | 全部 | "未匹配"展示为"有推荐标签" |
| 文件解析 | 全部 / 排队中 / 处理中 / 完成 / 失败 / 需要处理 | 全部 | "需要处理"覆盖解析、打标或页级失败 |
| 内容状态 | 正常 / 已作废 / 全部 | 正常 | 默认仅看正常内容 |
| 材料标签 / 页级标签 | 多选已启用标签 | 空 | 见上述匹配规则 |

**列表字段**：文件（类型、标题、内容编号、版本、来源）、材料标签（最多 2 个，可点击转为筛选）、审批信息（方式与编号）、有效状态、发布状态（取该内容最近更新的发布记录，无记录时展示"提交发布"）、最近更新、行操作。解析失败行提供"重新解析"，处理中展示"解析中"。

**排列规则**：列表按内容最近更新时间倒序展示，分页每页 8 条。

**整体流程**：进入内容库 → 设置筛选 → 浏览或勾选 → 单条进入详情或执行批量操作。

**关键状态**：页签已归档 / 待归档；内容正常 / 已作废；列表状态徽标覆盖解析中、解析失败、打标状态、有效状态与发布状态。

**待归档列表**：展示本人在进行中的批次，超级管理员展示全部。

| 项目 | 规则 |
| --- | --- |
| 筛选 | 关键词（匹配批次号与批次内全部标题）、批次类型（全部/上传归档/标签更新）、包含已结束批次（默认不勾选） |
| 列 | 批次/内容（首条标题，多条追加"等 N 份"，副行批次号后 12 位）、类型、发起人、提交时间、处理状态、操作 |
| 处理状态 | 已结束 / 解析打标中 / 匹配中 / 待确认结果，副行展示"已归档数/总数"及已确认、已取消数量 |
| 操作 | 进行中展示"继续处理"，已结束展示"查看结果"；具备对应权限且未结束时展示"取消剩余归档/取消剩余更新" |
| 发起人缺失 | 展示"已失效账号" |

**批量操作**：

| 操作 | 权限 | 行为 |
| --- | --- | --- |
| 批量发布 | 创建与提交发布 | 带入所选内容进入发布编辑 |
| 审批信息 | 编辑内容与审批 | 打开批量审批编辑器 |
| 导出 | 下载与导出 | 打开导出弹窗，范围为已选内容 |
| 作废 | 作废内容 | 填写作废原因后整批作废 |
| 取消选择 | 无 | 清空已选 |

**结果反馈**：无匹配时"没有匹配的内容 / 试试减少筛选条件，或更换关键词。"；批量作废未填原因提示"请填写作废原因。"；重新解析成功提示"正在重新解析整份文件。"

**权限控制**：上传按钮需上传权限；导出记录仅对导出权限展示；批量按钮在无对应权限时禁用。

## 六、上传与归档

### 6.1 功能目标与适用场景

**功能目标**：将"上传即入库"改为"先暂存解析、人工确认后再归档"，确保进入正式库的内容、素材与标签均经核对。

**适用场景**：新增内容、批量上传、上传新版本、上传后中断再继续、取消尚未归档的内容。

**核心规则**：上传成功表示文件已保存；解析完成仅表示可核对；**归档成功才表示成为正式内容**。解析完成不自动归档。

### 6.2 整体流程

```text
1 上传内容（暂存）
   ↓ 提交
2 解析打标（后台，可离开）
   ↓ 完成 / 失败
3 确认结果（逐份核对内容、素材、材料标签与页级标签）
   ↓ 确认
4 归档（统一提交，可部分成功）
```

- 单份解析成功即可进入确认，无需等待整批。
- 批次与处理结果跨页面、跨刷新保留；离开后可从内容库"待归档"或工作台继续。
- 提交后源文件与审批信息锁定；内容编号与版本号在归档时确定，暂存期展示的为预估值。

### 6.3 第 1 步：上传内容

**上传方式**：

| 方式 | 说明 | 限制 |
| --- | --- | --- |
| 上传文件 | 拖拽或点击选择，支持批量 | PDF、PPT、Word、图片、视频、HTML；上传新版本时仅 1 个文件 |
| 公开链接 | 每行一条，批量添加 | 仅 http/https，不含账号密码；上传新版本时仅 1 条 |

**取值与格式规则**：

- 文件类型按扩展名与 MIME 判定：pdf→PDF；ppt/pptx→PPT；doc/docx→Word；html/htm→网页；图片为 png/jpg/jpeg/webp/gif 或 image/*；视频为 mp4/mov/webm 或 video/*。无法识别时提示"不支持该格式，请移除此项；其他文件可继续归档。"，该项不可提交。
- 空文件或读取失败提示"文件无法读取或格式无效，请移除后重新添加。"。
- PDF 读取实际页数作为页数；HTML 提取正文（移除脚本、样式、内嵌框架），正文为空时以"该 HTML 文件没有可提取的正文。"占位，摘要取正文前 100 字。
- 每个文件生成内容指纹，用于重复判定。
- 单个文件不超过 200MB，单批不超过 50 份；超出时拒绝添加并提示拆分批次后重试。

**字段规则**：

| 字段 | 含义 | 必填 | 格式/取值 | 默认值 | 来源 | 联动与校验 |
| --- | --- | --- | --- | --- | --- | --- |
| 内容标题 | 内容名称 | 是 | 去除首尾空格后非空 | 文件名去扩展名 | 自动带出，可改 | 为空提示"内容标题必填" |
| 摘要 | 内容简介 | 否 | 文本 | HTML 取正文前 100 字，其余为空 | 自动/用户 | 用于发布与检索 |
| 封面 | 展示图 | 否 | image/* | 新版本继承上一版本 | 用户上传或示例图 | 非图片提示"请选择有效的图片文件。" |
| 缩略图 | 列表缩略图 | 否 | image/* | 新版本继承上一版本 | 用户上传或示例图 | 同上 |
| 补充视频 | 关联演示视频 | 否 | MP4/WebM/MOV，非空 | 无 | 用户上传 | 非法时"请选择非空的 MP4、WebM 或 MOV 视频文件。" |
| 公开链接 | 来源地址 | 条件必填 | http/https | 无 | 用户输入 | 非法时"请逐行填写不含账号密码的 HTTP / HTTPS 公开链接。" |
| 审批登记方式 | 是否登记审批 | 是 | 需要登记 / 不需要登记 | 需要登记 | 用户选择 | 无免登记权限时该项禁用 |
| 审批编号 | 审批单编号 | 登记时必填 | 文本，去除首尾空格 | 空 | 用户输入 | 为空提示"审批编号必填" |
| 有效期 | 审批有效期 | 登记时必填 | YYYY-MM-DD 合法日期 | 空 | 用户输入 | 非法提示"有效期必填" |
| 审批截图 | 审批凭证图片 | 登记时必填 | 图片，恰好 1 张 | 空 | 用户上传 | 0 张"请上传一张审批截图"，多张"每次只能上传一张审批截图" |

审批信息作用于本次上传的全部内容；上传新版本时以本次登记值为准，与原版本编号不同时按本次填写保存，历史版本保留原快照。封面、缩略图与补充视频按文件独立维护，不跨文件批量应用。

**版本判定规则**：

- 与库内"正常"内容（含历史版本）比对，内容指纹相同或来源链接相同，判定为同一内容并生成新版本；否则创建新内容。
- 同一批次内多份相同文件视为同一内容，版本号依次递增；显式"上传新版本"仅允许 1 份且目标必须存在。
- 批次内出现重复文件或链接时阻断提交，提示"本批次有重复文件或链接，请移除重复项。"。
- 新版本预计版本号为"目标当前最大版本 + 1"，仅供参考，归档时重新计算。

**提交校验顺序**：操作账号未变化 → 上传权限 → 条目非空 → 审批方式与审批完整性 → 条目标题与来源完整、链接合法、批次无重复 → 目标版本未变化。全部通过后暂存文件并创建批次；任一失败不创建批次。

**结果反馈**：成功提示"文件已暂存，正在解析打标。"并进入确认页；失败提示"批次未保存，请检查浏览器存储后重试。"或具体校验原因。

**离开保护**：存在未提交修改时离开需二次确认"本批次尚未提交暂存，离开后需要重新添加。确定离开吗？"；图片或截图正在保存时阻止离开并提示"文件正在保存，请稍候。"

### 6.4 第 2 步：解析打标

**业务规则**：

- 提交后条目进入"处理中"，逐份完成；批次内按顺序推进，处理时长随文件大小与页数增加，处理期间可离开页面。
- 解析完成时，标题、摘要与全文与已启用标签名称（统一全半角、忽略大小写）匹配，命中则绑定为材料标签，来源记为 AI；逐页正文匹配命中则绑定为该页标签，同一页同一标签不重复。
- 页级状态逐页置为"完成"；人工已绑定的标签保留，不被 AI 结果覆盖。
- 解析成功但打标失败时，仅打标状态为"失败"，可重试或人工完成核对，不与文件解析失败合并为不可恢复状态。
- 解析失败或任一页解析失败时，该份不可归档，仅可重试；不影响同批其他文件。

**关键状态**：处理中 → 完成 / 失败；打标中 → 已完成 / 失败。

**结果反馈**：解析完成生成通知"解析打标完成，待确认归档 / {N} 份内容可核对结果，尚未进入正式内容库。"，接收人为批次上传人。

### 6.5 第 3 步：确认结果

**页面结构**：左侧文件队列，右侧当前文件工作区；底部统一归档栏。

**文件队列**：

- 筛选：全部、待确认、处理中、已确认、已取消（存在取消项时展示），每项带数量。
- 每份展示类型、标题、文件名、素材标记（封面/缩略图/视频）、状态徽标。
- 默认选中当前文件，其次第一个未完成且未确认的文件，再次列表首项。
- 状态文案按优先级取首个成立项：已取消 → 已归档/已更新 → 解析打标中/匹配中 → 归档需处理/更新需处理 → 解析失败/匹配需重试 → 已确认 → 待确认。

**内容信息与素材页签**：

- 只读展示标题、摘要、封面、缩略图、补充视频；视频可直接播放，无法播放时提示"当前浏览器无法播放此视频，请上传 MP4 或 WebM 格式。"。
- "源文件与审批信息"区只读并标注"上传时已固定"，展示文件名、来源、审批方式、审批编号、有效期、截图名称。
- 点击"编辑内容信息"打开弹窗，可修改标题、摘要、封面、缩略图与视频；标题必填；保存后该份确认状态失效，需重新确认，但不触发重新解析。

**打标结果页签**：

- 左侧为内容预览（分页格式支持翻页、页码跳转、文内查找、缩放），右侧为标签核对。
- 作用范围切换"材料标签 / 页级标签"；页级模式可选择页码，仅展示该页标签。
- 标签按一级分类分组，展示名称、来源（AI/人工）、停用标记；可移除。
- "添加标签"弹窗支持搜索、按分类筛选；仅可选已启用且所属分类启用的二级标签；同位置已绑定的标签不可重复添加。
- 具备标签库权限且为上传归档批次时可"新建标签"：填写名称与分类，先执行相似检查，通过后创建并绑定；来自推荐时分类锁定。标签更新批次仅可选用已有标签。
- 推荐标签区展示未处理推荐及来源位置，可"选择已有标签""新建并采用""取消推荐"；已取消的推荐折叠展示并可恢复。
- 不要求处理推荐即可确认；推荐随归档内容、版本与页码保留，不自动创建标签。
- 无任何标签时允许直接确认，不设"无适用标签"勾选项。

**确认前置校验**（全部满足才可确认）：

| 校验项 | 提示 |
| --- | --- |
| 文件解析完成 | 请先完成文件解析 |
| 无页级解析失败 | 存在页面解析失败，请重新解析 |
| 标题非空 | 内容标题必填 |
| 标签识别完成 | 标签识别尚未完成 |
| 打标失败时已人工完成核对 | 请重试打标或人工完成标签核对 |
| 新上传批次不含停用或失效标签；标签更新批次允许保留原正式内容已有的停用绑定 | 存在已停用或失效标签，请移除或替换 |
| 标签页码在 1 至总页数之间 | 标签页码无效 |
| 审批信息完整（登记模式） | 缺少编号、有效期或截图，或存在未确认的识别差异 |
| 标签更新批次：正式内容与标签库未变化 | 正式内容已变化，请重新同步本文件 / 标签库已更新，请重新同步本文件 |

**确认与失效**：

- 确认记录确认人、确认时间与确认时的标签定义快照。
- 确认后修改标题、摘要、素材、标签、推荐处理结果，或重试任务，该份立即回到待确认，其他文件不受影响。
- 版本冲突：目标内容当前版本已变化时，提示"当前正式版本已变化，请核对本次更新目标。"，提供"按最新版本重新核对"，核对后需重新确认。

**结果反馈**：确认成功提示"本文件已确认。"，并自动进入下一份待确认文件；无下一份时停留在当前文件。

### 6.6 第 4 步：归档

**业务规则**：

- 底部按钮为"归档已确认的 N 份"，仅归档本次已确认且仍在进行中的条目；支持部分成功。
- 归档逐份校验，顺序为：确认状态未失效 → 标签定义未变化 → 文件与素材可用 → 确认前置校验仍通过 → 免登记权限仍有效 → 目标内容仍为"正常"且版本未变化。
- 归档成功生成内容与版本：新内容分配内容编号并归属批次上传人，版本号取该内容最大版本 + 1；记录归档时间、确认人与确认时间；登记模式生成独立审批凭证并关联本次版本。
- 未处理推荐转为推荐标签记录，按内容、版本与页码保留；仍有待处理推荐时打标状态置"未匹配"，否则"已完成"。
- 归档失败保留已确认结果与失败原因，修正后可直接重试，无需重新上传或重新核对。
- 同一明细只能成功归档一次；已完成明细展示"查看正式内容"。
- 全部条目归档或取消后批次结束，批次列表默认不再展示。

**结果反馈**：成功提示"归档成功 N 份"，存在失败时追加"，其余文件请查看提示后重试"；生成通知"内容归档完成 / 成功归档 N 份内容。"；归档失败单份提示具体原因，如"目标内容版本已变化或作废，请重新核对更新目标。"

### 6.7 取消归档

**适用范围**：解析中、待确认、已确认未归档、归档失败的条目；已归档条目不可取消。

**入口与确认**：

| 入口 | 范围 | 二次确认文案 |
| --- | --- | --- |
| 确认页页头"取消剩余归档" | 批次内全部进行中条目 | "本批次剩余 N 份文件将结束本次归档。" |
| 确认页当前文件底部"取消归档" | 当前条目 | "{标题}"将结束本次归档。 |
| 待归档列表行"取消剩余归档" | 批次内全部进行中条目 | 同上 |

影响说明固定为"再次入库需要重新上传。同批已归档文件及已有正式版本不受影响。"

**业务规则**：

- 取消记录取消人与时间，条目转为只读，不再计入待办、异常、已确认或可归档数量。
- 不删除标签字典、原文件或共享素材；后台任务返回结果不得写回已取消条目，也不重新产生待办。
- 重复取消不改变结果；取消后刷新仍保持取消状态。

**结果反馈**：成功提示"已取消 N 份内容的归档。"；失败提示"操作未保存，请重试。"

### 6.8 权限与数据范围

- 上传、确认、归档、取消均需"上传内容"权限，且仅限本人批次；超级管理员可处理全部批次。
- 提交时校验操作账号未变化，变化则提示"操作账号已变化，请重新打开上传页面。"。
- 权限被收回时阻止继续操作并说明原因，已保存的批次与日志保留。

## 七、内容详情与版本管理

**功能目标**：展示单份内容的完整信息、版本、审批、标签与发布记录，并提供受控的维护入口。

**适用场景**：核对归档结果、查看历史版本、修改内容信息、补充审批、作废、重新解析、进入发布。

**整体流程**：进入详情 → 选择版本 → 查看内容信息、审批、标签与发布记录 → 按权限执行编辑、作废、重新解析或进入发布。

**业务规则**：

- 默认展示当前版本；可通过版本下拉切换，历史版本只读并标注"历史版本只读"。
- 可编辑判定：具备对应操作权限、查看的是当前版本、内容为"正常"。
- 已作废内容展示"已作废"标识，不可编辑、不可上传新版本、不可提交发布。
- 版本历史按版本号倒序，展示版本号、标题、变更说明、归档时间，可切换查看。

**字段规则**：

| 区域 | 字段 | 说明 |
| --- | --- | --- |
| 内容信息 | 内容编号、当前版本、内容类型、来源、上传时间、结果确认（确认人＋时间）、归档时间、有效期、摘要、展示素材、来源原文 | 缺失时分别展示"历史内容，未单独记录""历史内容，未记录人工确认""未填写""未设置" |
| 审批信息 | 审批方式、审批编号、有效期、OCR 核对结论、审批截图、人工确认说明 | 无快照时按方式提示"此内容无需登记审批信息。"或"请补充审批信息，或按权限选择无需登记。" |
| 材料标签 | 标签名称、来源、停用标记 | 为空展示"尚未添加材料标签" |
| 页级标签 | 按页展示该页标签 | 分页格式提供页码导航 |

**关键状态**：当前版本 / 历史版本（只读）；正常 / 已作废；审批待补充 / 已登记 / 免登记；解析与打标状态。

**编辑内容信息**：可修改标题（必填，为空提示"请输入内容标题"）、摘要、封面、缩略图；免登记内容可维护有效期。保存后更新内容更新时间，保留文件版本与审批信息。

**作废**：填写"作废原因"（必填，为空提示"请填写作废原因"），确认后置为"已作废"，历史版本保留；批量作废对所选内容统一写入同一原因。

**重新解析**：仅对当前版本、内容"正常"、且存在解析或页级失败的版本开放；具备编辑权限；处理中不可重试；重试后全部页级状态重置并重新打标，提示"正在重新解析整份文件。"。

**页面入口**：下载原文件（需导出权限）、上传新版本（需上传权限且内容正常）、提交发布（需发布权限且为当前正常版本）、导出内容包（需导出权限）、操作审计（需审计权限，按内容编号带入查询）、发布记录（带内容筛选进入发布管理）。

## 八、审批登记

**功能目标**：为内容登记可追溯的审批凭证，识别并人工确认 OCR 差异，控制内容有效期。

**适用场景**：上传时登记审批、为已有内容补充或更换审批、批量设置审批、选择免登记、复用历史审批信息。

**业务规则**：

- 审批与版本绑定，每个版本保存独立快照；历史版本与已提交发布记录保留各自快照，不随新版本变化。
- 审批方式三态：待补充（未完成）、已登记、免登记。归档时"待补充"不允许通过。
- 免登记需"免登记审批"权限；无权限时该选项禁用并提示"当前角色没有免登记权限"。
- 同一审批编号可重复登记，每次保存生成新的凭证修订并仅关联本次内容版本；复用历史信息时给出提示"此编号已有登记；保存将新增审批修订，仅关联本次内容版本。"
- 审批编号不是内容编号，不作为内容唯一标识。
- 有效期用于有效状态计算与发布校验：到期前 30 个自然日标记"即将过期"，到期后标记"已过期"；到期仅标记，不自动下架或作废。

**字段规则**：

| 字段 | 含义 | 必填 | 格式/取值 | 默认值 | 来源 | 校验提示 |
| --- | --- | --- | --- | --- | --- | --- |
| 审批方式 | 是否登记 | 是 | 需登记 / 无需登记 | 上传时默认需登记；批量编辑时若所选内容全部免登记且有权限，默认无需登记 | 用户选择 | 无权限时"当前角色没有免登记权限。" |
| 审批编号 | 审批单编号 | 登记时必填 | 文本，去除首尾空格 | 空 | 用户输入或复用 | "审批编号必填" |
| 有效期 | 审批有效截止日 | 登记时必填 | YYYY-MM-DD 合法日期 | 空 | 用户输入或复用 | "有效期必填" |
| 审批截图 | 凭证图片 | 登记时必填 | 图片，恰好 1 张 | 空 | 用户上传 | "请上传一张审批截图"/"每次只能上传一张审批截图" |
| 审批单标题 | 审批单名称 | 否 | 文本 | 空 | OCR 识别或复用 | 与登记标题不一致时提示人工核对 |
| OCR 差异确认 | 差异确认标记 | 有差异时必经 | 布尔 | 未确认 | 用户确认 | "请人工确认 OCR 异常" |

**OCR 差异规则**：

- 对审批截图比对编号、有效期与标题，输出差异：无法识别编号、编号不一致、有效期不一致、标题需人工核对。
- 存在差异时提交需二次确认，弹窗展示填写值与识别值，确认后按填写值保存，原始识别结果与人工确认记录保留。
- 任何字段修改后差异确认失效，需重新确认。
- 查看或下载已保存截图需"查看与下载审批截图"权限；无权限时提示"截图已关联，当前账号没有查看已保存截图的权限。"

**整体流程**：选择审批方式 →（登记）填写编号、有效期、上传截图 → 系统识别并比对 → 存在差异时人工确认 → 保存生成凭证修订。免登记仅保存方式，不校验字段。

**关键状态**：待补充 → 已登记 / 免登记；识别结果一致 / 存在差异 / 无法识别；差异未确认 → 已人工确认。

**批量审批**：对所选内容的当前版本统一应用同一审批信息。所选内容须全部可访问且为"正常"内容，任一不满足时编辑器不可用并提示"仅可编辑有权限访问的正常内容当前版本。"。保存前校验所选范围未变化，内容、版本或审批快照变化时提示"内容或审批信息已更新，请关闭后重新打开。"。

**结果反馈**：成功"审批信息已保存。"；字段缺失逐项提示；保存失败"审批信息未保存，请检查权限和浏览器存储后重试。"

## 九、标签管理

### 9.1 功能目标与结构

**功能目标**：集中维护两级标签体系，统一各入库入口的相似检查，按来源处理推荐标签，并将最新标签批量同步到已有内容。

**适用场景**：新增或调整标签、批量导入标签、处理识别出的新标签建议、标签治理后回补已有内容。

**结构**：标签库与推荐标签两个页签。标签为两级结构，一级为分类，二级为可用标签；不支持第三级。标签字段：

| 字段 | 含义 | 必填 | 取值 | 默认值 | 来源 | 规则 |
| --- | --- | --- | --- | --- | --- | --- |
| 名称 | 标签名 | 是 | 去除首尾空格后非空 | 空 | 用户输入 | 同层级规范化后唯一 |
| 所属分类 | 一级标签 | 二级标签必填 | 已有一级标签 | 空 | 用户选择 | 二级只能归属一级；一级标签不可挂父级 |
| 启用 | 是否可新增使用 | 是 | 是/否 | 是 | 用户选择 | 停用后不再新增绑定，已有绑定保留 |
| 对外展示 | 是否可对外展示 | 是 | 是/否 | 否 | 用户选择 | 仅影响展示，不影响绑定 |

标签库左侧为分类列表，右侧为该分类下的标签；支持按一级或标签名称搜索，搜索时保留分类结构并只展示命中项。每个标签展示名称、停用状态、对外展示标记与操作按钮；分类与标签的编辑均通过弹窗完成，启停在编辑弹窗中确认后生效。

**业务规则**：

- "可用标签"判定：标签自身启用，且二级标签的所属一级分类存在且启用。
- 同一层级下名称规范化后（统一全半角、去除首尾空格、忽略大小写）重复时硬阻断，提示"该层级下已有同名标签"；药物剂量、疾病分期与符号差异不得通过规范化合并。
- 停用标签保留已有绑定并在界面标注"已停用"；一级分类停用时其下标签不可新增，已有绑定保留。
- 标签不提供删除，仅可停用；使用数量按"任一版本存在该标签或其子标签绑定"的文件数统计。
- 修改名称或分类时保留已有绑定（按标签 ID），并记录修改前的名称快照。

**权限控制**：查看标签库需"标签管理"菜单；新增、编辑、启停、导入需"维护标签库与推荐"；无权限时页面提示"当前角色仅可查看标签，新增、编辑与启停需要标签管理权限。"

**整体流程**：维护标签库 →（可选）通过导入批量调整 → 处理推荐标签 → 需要时发起"同步最新标签到文件" → 逐份确认后更新内容标签。

### 9.2 相似检查

**适用范围**：手动新增标签、编辑名称或所属分类、推荐采纳时新建标签、待归档确认页新建标签、Excel 导入，全部入口执行同一规则。

**规则**：

- 先执行同层级精确重名阻断，再执行相似检索。
- 按规范化名称计算字符相似度，达到 0.7 视为相似；同级比较（一级只比一级，二级只比二级）；同分类候选优先，其次按相似度降序，最多展示 5 个。
- 相似为软提醒：展示候选名称、所属分类路径、启用状态与"同分类/其他分类，名称相近"，用户可选择"返回修改"或"仍然创建/仍然保存"。
- 候选只读，不可选择，不提供"使用已有标签"。
- 保存时以最终名称与分类重新检查，并校验标签库未变化；标签库已变化时提示"标签库已变化，请返回并重新检查。"。名称或分类调整后原确认失效。
- 用户选择"仍然创建"后生成正常的新增记录，不要求填写理由，不展开候选明细。

**结果反馈**：校验失败提示"存在相似标签或标签库已变化，请重新检查后确认是否仍然入库。"

### 9.3 标签导入与导出

**模板结构**：`.xlsx`，含"标签分类"与"标签"两个工作表。

| 工作表 | 列 |
| --- | --- |
| 标签分类 | ID、名称、启用、对外展示 |
| 标签 | ID、名称、启用、对外展示、分类ID、分类名称 |

**导入规则**：

- 工作表缺失或表头不符时拒绝并提示使用模板；"启用""对外展示"仅接受"是/否"；含公式时提示"请填写文本，不支持公式"。
- 按"标签分类"先于"标签"的顺序处理；分类不存在、改变标签级别、文件内重复标签均按行报错。
- 预览展示每行位置、名称、变更内容（含改名与影响说明）、相似候选与处理选择（仍然入库/跳过该行）、错误原因；汇总新增、更新、无变化、错误数量与受影响文件数。
- 提交条件：无错误行、全部相似项已选择处理方式、新增与更新数量大于 0；提交前校验标签库未变化。
- 导入为整批提交，存在未处理错误时不提交任何行。
- 有改名或改分类时，保存前记录现有绑定名称，保证历史显示可追溯。

**导出与模板**：提供"下载模板"，生成含两个工作表、表头与列宽的空模板；"导出全部标签"需导出权限，生成"标签库.xlsx"，结构与模板一致并包含现有数据。

### 9.4 推荐标签

**来源与结构**：推荐按"内容＋版本＋页码"记录来源位置；材料级来源页码为空。每条推荐独立维护每个来源的采纳、取消状态。

**状态计算**：全部来源已采纳为"已采纳"；全部已取消为"已取消"；全部来源均已处理为"已处理"；部分处理为"部分处理"；否则"待处理"。

**操作规则**：

| 操作 | 权限 | 规则 |
| --- | --- | --- |
| 采纳并添加 | 内容标签；需新建标签时另需标签库 | 同名标签已存在且可用时直接绑定；否则先相似检查后创建并绑定到该来源位置 |
| 取消推荐 | 内容标签 | 仅取消该来源，不影响其他来源；不删除标签、不撤销已采纳绑定 |
| 恢复推荐 | 内容标签 | 恢复后该来源重新可采纳 |
| 取消待处理推荐（汇总） | 标签库 | 取消该推荐全部待处理来源，已采纳绑定保留，已取消来源可恢复 |
| 忽略推荐 | 标签库 | 整条推荐不再提示，已采纳绑定保留 |

**约束**：仅当前正常版本可处理；历史版本只读；来源版本或页码失效时不可采纳，提示"来源版本已不可用""来源页码已不可用"。

**业务规则**：人工取消或移除某位置的同名标签后，下次匹配或重新启用不自动补回；推荐名称或分类变化时按新定义重新识别。

### 9.5 同步最新标签到文件

**功能目标**：标签库集中维护后，由用户主动发起一次批量匹配，仅补充尚未绑定的标签位置。

**发起条件**：同时具备"维护标签库与推荐"和"维护内容标签"权限；同一时间仅允许一个未结束的标签更新批次，存在时再次点击进入已有批次。

**文件范围**：

- 默认"选择部分文件"，可切换"全部文件"。
- 可选文件为当前版本解析完成、页级无失败、内容"正常"的正式内容。
- 不参与：待归档文件、历史版本、已作废或已取消文件、解析未完成文件。
- 部分文件支持按标题或编号搜索、格式与来源筛选、分页、逐行勾选、本页全选、跨页保留、仅看已选、清空选择；筛选与翻页不改变已选范围；未勾选时不可提交。
- 提交前校验所选文件状态未变化，变化时提示"所选文件状态已变化，请重新选择后同步。"，不静默缩小或扩大范围。

**匹配规则**：

| 场景 | 结果 |
| --- | --- |
| 新增已启用标签 | 命中则加入对应材料或页面 |
| 新增停用标签 | 不参与匹配，不新增绑定 |
| 一级分类停用 | 该分类下标签不参与匹配，已有绑定保留 |
| 文件已有标签 | 保留自动与人工绑定，不重算、不重复添加；材料与各页分别判断 |
| 原有标签被停用 | 保留已有绑定并标注停用，不新增 |
| 标签重新启用 | 所属分类启用时，下次主动同步补充未绑定位置；人工取消记录仍生效 |
| 标签改名 | 已有绑定按 ID 保留并显示新名称；未绑定位置按新名称匹配 |
| 标签改分类 | 已有绑定保留并按新分类展示；新分类启用时继续匹配未绑定位置 |
| 原有自动标签本次未命中 | 保留已有绑定，不自动移除 |
| 仅修改对外展示 | 绑定不变，无需重新同步 |

- 匹配复用已有解析内容，仅计算材料整体与各页正文；同一标签在不同页独立绑定。
- 计算阶段仅写入"标签更新"批次，不修改正式内容；结果需逐份确认后统一更新。
- 任务启动时固定标签定义与文件版本；计算、确认与保存阶段均重新校验名称、分类、启停、文件内容与版本，任一变化则该文件不可保存并提示重新同步。

**确认与更新**：

- 复用上传确认页的文件队列、预览、素材查看与标签编辑；默认打开"打标结果"，仅标签可维护，其他信息只读。
- 直接展示"已有标签＋本次补充标签"的完整结果，不展示增删建议或分类统计。
- 支持材料标签与页级标签增删；原有停用标签允许保留，不允许新增停用标签。
- 逐份确认后点击"更新已确认的 N 份"，仅将结果写入对应内容的当前版本。
- 更新后内容保持已归档，不生成新版本、不修改源文件、审批、素材与已提交发布快照，不自动重新发布。
- 修改已确认结果会取消该份确认，其他文件不受影响。
- 批次页头可取消剩余更新，文件底部可取消本次更新；已更新项不回滚，尚未更新的正式标签保持原样。

**结果反馈**：同步发起后提示"后台执行，可稍后查看；结果确认后生效。"；匹配完成通知"标签匹配完成，待确认结果 / 查看每份文件的完整标签结果，确认后更新。"；更新成功提示"标签更新成功 N 份"，并生成通知"标签更新完成 / 已更新 N 份内容的标签。"

**异常处理**：单文件失败就地提示并可重试，失败或未参与计算不得视为"无标签"；重试读取当前内容与标签库并清除原确认；取消后后台结果不写回。

### 9.6 与内容模块的联动

- 内容详情的标签维护直接写入当前版本，仅影响该版本，不触发重新匹配。
- 同步更新只作用于当前版本；历史版本标签只读。
- 标签启停不改变已有绑定；需要移除时由用户在内容或同步结果中明确操作。
- 标签改名或改分类后，已有绑定按标签 ID 保留；同步更新确认后按新名称、新分类展示并保存名称快照，未更新的历史版本仍按原快照展示。

**关键状态**：标签启用 / 停用；一级分类启用 / 停用；推荐待处理 / 部分处理 / 已采纳 / 已取消 / 已忽略；标签更新批次处理中 / 待确认 / 已更新 / 已取消。

## 十、发布管理（二期功能）

**功能目标**：将已归档内容排期提交至下游发布平台，保存发布快照并查看发布预览与结果。

**适用场景**：单份或批量排期发布、查看发布状态与预览、基于历史记录新建发布。

**业务规则**：

- 仅"已归档"的当前版本可发布；待归档、历史版本、已作废内容不可选。
- 发布记录与内容版本绑定，提交时保存该版本快照；后续内容更新不改变已提交记录。
- 同一条记录只能编辑自身关联内容，草稿可继续填写；已提交记录需另建发布。
- 批量提交整体校验，任一份不通过则整批不提交，不允许部分成功。
- 记录状态：草稿、待发布、已发布、发布失败；发布失败保留原因并允许基于最新版本另建记录。

**可发布校验**（全部满足）：

| 校验项 | 提示 |
| --- | --- |
| 内容未过期 | 内容已过期，请先更新有效期 |
| 内容为正常 | 内容已作废 |
| 解析完成 | 请先完成文件解析 |
| 审批非待补充 | 请先补充审批信息 |
| 标签识别已完成，或仅存在待处理推荐 | 标签识别尚未完成 / 请先完成标签识别 |
| 封面已设置 | 请上传封面或选择默认图片 |
| 缩略图已设置 | 请上传缩略图或使用封面 |
| 拟发布时间不晚于有效期截止日 | 拟发布时间超过内容有效期 |

**字段规则**：

| 字段 | 必填 | 取值 | 默认值 | 来源 | 校验提示 |
| --- | --- | --- | --- | --- | --- |
| 发布标题 | 是 | 去除首尾空格后非空 | 内容当前标题 | 自动带出可改 | "《{标题}》缺少发布标题。" |
| 摘要 | 否 | 文本 | 内容摘要 | 自动带出可改 | 无 |
| 发布封面 | 提交时必填 | 图片 | 内容封面 | 自动带出可改 | "请上传封面或选择默认图片" |
| 缩略图 | 提交时必填 | 图片 | 内容缩略图或封面 | 自动带出可改 | "请上传缩略图或使用封面" |
| 拟发布时间 | 提交时必填 | 北京时间，精确到分钟，且晚于当前时间 | 空 | 用户选择 | "请选择未来的拟发布时间（北京时间）。" |

**整体流程**：新建发布 → 选择内容（可搜索、按类型/来源/标签筛选、仅看可发布）→ 下一步核对信息与排期 → 保存草稿或提交发布 → 生成记录 → 查看详情与预览。

**交互规则**：

- 选择阶段已选内容跨筛选保留；已选列表可移除；编辑草稿时不可更换内容。
- 存在问题的内容不可勾选，就地展示阻断原因；审批"待补充"时提供"补充审批信息"入口。
- 核对阶段按内容切换，逐份核对标题、摘要、封面与缩略图；内容已有新版本时提示"内容已更新，请同步最新版本后核对。"并提供同步。
- 支持"明天 10:00""三天后 10:00"快捷设置时间；所选内容共用同一排期，每份分别生成记录。
- 记录对应版本落后于当前版本时提示"本记录对应 V{n}.0，当前内容为 V{m}.0。原发布状态与预览保留；如需发布新版本，请另建发布记录。"

**结果反馈**：保存草稿提示"已保存 N 条发布草稿。"；提交提示"已提交 N 份内容，各自生成发布记录。"；校验失败按内容逐条展示原因。

**发布详情与预览**：展示状态、标题、内容编号与版本、拟发布时间、失败原因、预览卡片（瑞医空间·微网站/企微端/微信端）、提交时间、发布人、最近反馈、摘要。预览可打开、复制链接、生成二维码；预览版本与记录修订不一致时提示"此预览已更新"。

**关键状态**：草稿 → 待发布 → 已发布 / 发布失败；记录版本可能落后于内容当前版本，原记录状态与预览保留。

**权限控制**：新建、编辑草稿与提交发布需"创建与提交发布"；查看需"发布管理"菜单；批量发布入口在内容库，需同一权限。

## 十一、公众号采集

**功能目标**：展示已采集的公众号文章及其与正式内容的关联，支持阅读与补充审批。

**适用场景**：查看采集结果、核对原文、跳转关联内容、为关联内容补充审批。

**整体流程**：进入采集列表 → 按公众号或关键词筛选 → 预览文章或跳转关联内容 → 必要时补充审批。

**业务规则**：

- 仅展示采集成功且存在正文的文章；采集失败或无正文的文章不进入列表。
- 按公众号筛选（全部公众号及自免医时空、爱医慢时空、爱医时空、爱眼医时空），支持标题与公众号关键词搜索。
- 列表字段：文章标题、公众号、原始链接、采集时间、操作。原始链接仅展示合法的 http/https 地址，非法时标记"链接无效"；支持复制链接。
- 操作：预览文章（弹窗展示正文）、查看内容（跳转关联内容详情）、补充审批（仅关联内容审批为"待补充"且有编辑权限时展示）。
- 本模块只读，不提供采集任务的新增、编辑或删除，不产生用户写入审计记录。

**权限控制**：需"公众号采集"菜单；补充审批另需"编辑内容与审批"。

**关键状态**：仅"采集成功且有正文"的文章可见；关联内容缺失时仅保留文章本身，不展示"查看内容"与"补充审批"。

**结果反馈**：无匹配时"暂无匹配的文章"；复制成功"链接已复制"，失败"复制失败，请手动复制链接"。

**补充规则**：采集结果若需进入正式内容库，复用上传与归档的暂存、确认、归档规则，不直接写入正式内容。

## 十二、系统管理

**功能目标**：维护账号、角色与批量账号数据，作为全系统身份与权限的基础。

**适用场景**：新员工开通账号、调整角色权限、批量创建账号、导出账号清单。

**整体流程**：创建角色并配置菜单与权限 → 创建或批量导入账号并分配角色 → 按需启停或导出。

**关键状态**：账号启用 / 停用；角色可编辑 / 系统保留；有关联账号的角色不可删除。

### 12.1 用户管理

**功能目标**：维护登录账号及其角色归属。

**字段规则**：

| 字段 | 含义 | 必填 | 格式/取值 | 默认值 | 来源 | 校验提示 |
| --- | --- | --- | --- | --- | --- | --- |
| 姓名 | 显示名称 | 是 | 去除首尾空格后非空，≤60 字符 | 空 | 用户输入 | "请输入姓名。" |
| 工号 | 登录身份 | 是 | 去除首尾空格并转大写，≤64 字符，不含空格与 @，全库唯一（含停用账号） | 空 | 用户输入 | "请输入有效的工号（不超过 64 个字符，不能包含空格或 @）。"/"该工号已存在，请使用其他工号；停用账号的工号也不能重复。" |
| 角色 | 权限来源 | 是 | 自建角色，不含超级管理员 | 空 | 用户选择 | "请选择自建角色；超级管理员角色不可分配。" |

**业务规则**：

- 新建账号默认启用，创建时间取当前时间。
- 超级管理员账号不可编辑、不可停用；当前登录账号不可停用，也不可改为无系统管理入口的角色。
- 停用后不可登录，内容与历史记录保留；启用后按角色权限恢复。
- 仅存在超级管理员一个角色时，创建账号表单提示"请先在角色管理中创建角色，再创建账号。"

**结果反馈**：创建成功"账号已创建，可使用该工号登录。"；编辑成功"用户信息已保存。"；停用成功"账号已停用，内容和历史记录保留。"；启用成功"账号已启用。"

### 12.2 角色管理

**功能目标**：按模块组合菜单入口与操作权限，形成可复用的权限集。

**字段规则**：

| 字段 | 必填 | 取值 | 默认值 | 校验提示 |
| --- | --- | --- | --- | --- |
| 角色名称 | 是 | ≤60 字符，忽略大小写唯一 | 空 | "请输入角色名称。"/"角色名称已存在。" |
| 菜单入口 | 至少 1 项 | 七个菜单 | 新建时为工作台、内容库 | "请至少选择一个菜单入口。" |
| 操作权限 | 否 | 见权限清单 | 空 | 权限未开所属菜单时"请同时开启"{模块}"菜单，或取消其操作权限。" |

**联动规则**：

- 勾选模块菜单：仅加入菜单；勾选"系统管理"时同时授予"管理账号与角色"。
- 取消模块菜单：移除菜单并移除该模块全部操作权限。
- 勾选操作权限：自动开启所属模块菜单。
- 取消"管理账号与角色"：同时移除"系统管理"菜单。
- 系统管理菜单与"管理账号与角色"权限必须同时存在或同时不存在。

**业务规则**：

- 超级管理员角色只读，展示全部权限，不可修改、删除或分配。
- 有任一关联账号的角色不可删除，提示"该角色仍有关联账号，请先为这些账号更换角色，停用账号也需调整。"
- 编辑角色保存后对全部关联账号即时生效。

**结果反馈**：创建"角色已创建，可在创建账号时分配。"；保存"角色已保存，关联账号同步生效。"；删除"角色已删除。"

### 12.3 用户导入

**功能目标**：批量创建账号，不修改或停用已有账号。

**模板与字段**：`.xlsx`，工作表"用户"，表头依次为"姓名""工号""角色名称"；模板附"可分配角色"工作表，排除超级管理员角色。

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 姓名 | 是 | 去除首尾空格 |
| 工号 | 是 | 按文本读取与写入，保留前导零；单元格为数字时提示"工号必须为文本，请按模板填写以保留前导零" |
| 角色名称 | 是 | 必须匹配已有自建角色，不存在时报错，不自动创建 |

**校验与提交**：

- 逐行校验：文件内重复工号、系统内重复工号（含停用）、角色不存在、必填缺失、工号格式、姓名缺失。错误行展示原文件行号与原因。
- 存在任一错误时整批不提交，可下载错误明细（原文件行号、姓名、工号、角色名称、错误原因），修正后重传。
- 提交前校验账号与角色数据未变化，变化时提示"账号或角色已变化，请重新预览导入"。
- 全部通过后统一创建，新账号默认启用；重传时已存在的工号按重复工号报错并整批不提交，避免重复创建。

**结果反馈**：成功"用户已批量创建，可使用工号登录。"，并展示"成功创建 N 个账号，默认启用；已记录操作审计。"。

**补充规则**：本期仅支持新增。后续如需通过导入更新或停用账号，须单独定义匹配键、可更新字段与冲突处理，不与新增混用同一模板。

### 12.4 用户导出

- 范围：默认导出当前搜索/筛选结果的全部行（跨分页），可切换为全部用户；导出前明确展示账号数量。
- 字段：姓名、工号、角色名称、启用状态、创建时间。
- 工号列强制为文本格式，保留前导零。
- 仅导出账号信息，不含密码、令牌等认证数据。
- 导出属于查询操作，不写入操作审计；导出结果不作为可批量更新账号的文件。
- 权限：需"管理账号与角色"，不使用内容导出权限。

## 十三、操作审计

**功能目标**：回答"谁、在什么时间、在哪个模块、执行了什么写入操作、结果如何"，用于追溯内容、标签、审批与账号变更。

**适用场景**：排查内容或标签异常、核对审批信息变更、审计批量导入结果。

**整体流程**：设定时间范围与筛选条件 → 浏览记录 → 按操作说明定位对象 → 转入对应模块处理；审计页不直接修改数据。

**记录范围**：

| 模块 | 记录的用户写入操作 |
| --- | --- |
| 内容库 | 提交上传、保存确认结果、确认归档、取消归档、确认并更新标签、修改内容信息、修改内容标签、作废、重新解析、重试失败任务、采纳/取消/恢复推荐 |
| 发布管理 | 保存发布草稿、提交发布 |
| 标签管理 | 新增/编辑/启停标签、导入标签、忽略推荐、发起/重试/取消标签同步、取消待处理推荐 |
| 系统管理 | 创建/修改/启停账号、创建/修改/删除角色、批量创建用户 |
| 公众号采集 | 当前无用户写入操作，保留筛选项并展示空态 |

**不记录**：查询、浏览、搜索、下载、导出、登录、退出、通知已读，以及系统解析、自动匹配、任务完成、轮询等自动任务。

**字段规则**：

| 字段 | 说明 |
| --- | --- |
| 操作时间 | 北京时间完整日期时间 |
| 操作人 / 工号 | 姓名与工号快照；缺失时展示"未记录工号" |
| 所属模块 | 内容库 / 发布管理 / 标签管理 / 系统管理 / 公众号采集 |
| 操作 | 动作名称，如"修改内容标签""批量创建用户" |
| 操作说明 | 内容编号、标签名、账号或批量数量等简要信息，最多 70 字符，超出截断并加省略号；不展示字段前后值与逐项明细 |
| 结果 | 成功 / 失败 / 部分成功；历史缺失时展示"未记录" |

**业务规则**：

- 以一次用户提交为一条记录，批量操作保留一条汇总，不按字段或明细拆分。
- 业务变更与成功日志同时保存；写入失败时保留失败结果，不产生成功记录；表单输入校验不单独记录。
- 模块归属：内容与内容标签变更归"内容库"；标签库与推荐维护归"标签管理"；账号与角色归"系统管理"；发布归"发布管理"。
- 页面只读，不提供编辑、删除与导出。
- 历史记录仅展示可识别的用户写入操作，缺失工号、结果与人工确认信息显示"未记录"，不回填或补造。

**筛选字段**：

| 字段 | 取值 | 默认值 |
| --- | --- | --- |
| 开始日期 / 结束日期 | 日期，开始不晚于结束 | 默认最近 7 天（开始为 6 天前，结束为当天）；按内容编号查询时不限开始日期 |
| 操作人 / 工号 | 姓名或工号关键词 | 空 |
| 所属模块 | 全部模块或五个模块 | 全部 |
| 操作 | 全部操作或当前模块下已有操作名称 | 全部 |
| 关键词 | 匹配操作名称与操作说明 | 空；按内容编号进入时预填编号 |

**结果反馈**：展示"共 N 条操作记录"，按时间倒序，分页每页 10 条；无结果时"暂无匹配的操作记录 / 可扩大时间范围或调整模块等筛选条件。"；无权限时"没有操作审计查看权限 / 请联系管理员配置独立的审计查看权限。"

**关键状态**：记录结果成功 / 失败 / 部分成功；历史缺失结果为"未记录"。

**权限控制**：仅"查看操作审计"权限可访问；该权限不附带内容编辑、系统管理或审批截图查看能力。审计页只读。

## 十四、导出与下载

**功能目标**：将内容及其结构化信息打包导出，满足留档、交接与外部核对需要。

**适用场景**：单份或批量导出内容资产、下载原文件、查看历史导出结果。

**整体流程**：选择内容或版本 → 确认是否包含审批截图 → 生成文件包 → 在导出记录下载。

**关键状态**：导出任务处理中 / 完成 / 失败；失败保留原因并允许重新导出。

**内容资产导出包**：

- 入口：内容库批量导出（范围为已选内容）、内容详情"导出内容包"（范围为当前版本）；需"下载与导出"权限。
- 包内容：按"内容编号/V{版本}"分目录，包含原文件（网页内容为转存的文本 HTML）、metadata.json（编号、版本、标题、类型、来源、摘要、作者、视频信息、创建时间、有效期、审批信息、标签及来源与页码）、封面与缩略图、补充视频、可选的审批截图，根目录 manifest.json 记录生成时间、数量、是否含截图与缺失资源说明。
- 审批截图默认不包含；勾选需"查看与下载审批截图"权限，无权限时该项禁用并标注"（当前角色无此权限）"。
- 无法获取原文件或原始资源时，在清单中标注原因，不以示例文件替代。
- 命名规则：`恒瑞CMS_内容资产_{YYYY-MM-DD}.zip`。
- 生成过程写入导出任务，成功后可在"导出记录"下载；失败保留错误信息并允许重新导出。

**下载原文件**：需"下载与导出"权限；文件不可用时提示"原文件暂不可用"。

**导出记录**：仅列出包含当前用户可见内容的导出任务，展示文件包名称、生成时间、状态、结果；可下载或重新导出；无记录时"暂无导出记录"。

## 十五、跨模块联动与冲突处理

| 场景 | 影响 | 处理规则 |
| --- | --- | --- |
| 未归档内容 | 内容库、工作台、发布、导出 | 不计入正式内容数量与检索；不可发布、不可导出；仅出现在待归档与工作台待确认 |
| 归档生效版本 | 内容库、详情、发布 | 新版本归档后才切换为当前版本；归档前旧版本继续作为正式当前版本 |
| 归档时目标版本已被他人更新 | 上传与归档 | 阻止归档并提示重新核对；核对后以最新版本为基准，需重新确认 |
| 内容作废 | 待归档、发布、标签同步、工作台 | 阻止继续归档与发布；从同步范围与待办中移除；历史版本可查 |
| 标签停用或分类停用 | 内容标签、同步、推荐采纳 | 已有绑定保留并标注；不再新增绑定；不参与自动匹配；不阻断标签更新（同步结果允许保留原停用绑定），但新上传批次不得携带停用标签 |
| 标签改名或改分类 | 历史绑定、同步结果 | 已有绑定按 ID 保留并显示新名称；未绑定位置按新定义匹配；同步任务启动后标签库变化则该文件需重新同步 |
| 审批变更 | 内容版本、发布、有效期 | 仅作用于本次版本；历史版本与已提交发布快照保留各自审批快照；有效期变化即时影响有效状态与发布校验 |
| 人工移除标签 | 后续匹配 | 记录排除项，下次匹配或标签重新启用不自动补回 |
| 取消归档 | 待办、通知、任务 | 条目转只读、退出待办与计数；后台结果不写回；再次入库需重新上传 |
| 取消标签更新 | 正式内容 | 已更新项不回滚，未更新项保持原样；任务停止，后续返回结果不写回 |
| 多页面同时操作 | 全部写操作 | 提交前读取最新数据并校验版本、标签定义、权限；冲突时阻止写入并提示重新核对 |
| 权限被收回 | 进行中的批次 | 阻止继续确认、归档、更新与取消，保留已保存数据与日志 |
| 账号停用 | 登录与操作 | 立即不可登录，权限失效；其批次可由超级管理员继续处理 |

## 十六、全局规则与异常处理

**提示与反馈**：所有操作给出明确结果；成功使用 toast；字段错误就地展示并聚焦首个错误项；阻断性错误说明原因与下一步动作，不使用"操作失败"作为唯一提示。

**重复提交防护**：提交、归档、取消、同步、保存等写操作在处理期间锁定入口，重复点击不产生第二条记录；同一明细只成功归档一次。

**并发与数据一致性**：写操作基于最新数据执行；校验失败不写入任何数据；业务数据与审计记录在同一提交内保存，避免出现"有变更无日志"或"有成功日志无变更"。

**异常兜底**：存储不可用时提示"浏览器存储空间不足，操作未保存。请导出已有内容后释放空间。"；读取失败提示"保存的数据无法读取，本次操作未提交，请重新加载。"；跨页面数据损坏提示"其他页面保存的数据无法读取，请重新加载后再操作。"

**空态**：所有列表、筛选项、弹窗候选均提供空态说明与可执行的下一步，不以空白页面代替。

**时间与数值**：日期展示统一北京时间；有效期按自然日计算，剩余天数小于 0 为已过期，0 至 30 天为即将过期；文件大小小于 1MB 以 KB 展示（向上取整），否则以 MB 展示（保留 1 位小数）。

**实现边界**：原型以浏览器本地存储与模拟任务运行。正式研发须由服务端提供文件存储与解析、标签相似检索、任务持续执行、身份认证、权限校验、归档幂等与并发控制、审计可靠留存，并保证上述输入输出约束与状态判定在服务端一致实现。
